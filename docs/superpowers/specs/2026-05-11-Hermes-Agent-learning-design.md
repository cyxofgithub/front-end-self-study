# Hermes Agent 学习文档 — 设计规格

**状态**：已定稿（与 2026-05-11 评审一致）  
**范围**：仓库内 Markdown 学习材料（非 Hermes Agent 源码实现）  
**对象**：Hermes Agent（Nous Research 开源自托管 AI Agent）

---

## 1. 背景与目标

### 1.1 主题定义

Hermes Agent 指 Nous Research 维护的开源、可自托管 AI Agent 框架，具备持久记忆、多平台网关、丰富工具与子代理等能力。官方入口包括但不限于：

- 项目站：<https://hermes-agent.org/>
- 开发者文档（架构、Agent 循环等）：<https://hermes-agent.nousresearch.com/docs/developer-guide/architecture>

### 1.2 文档目标

交付 **两篇正文 + 一篇总索引** 的学习型 Markdown：

1. **总索引**：定义、读者、版本策略、阅读路径与文件导航。  
2. **上篇 — 快速上手**：以「本地可复现的最小闭环」为主，安装、配置、验证与常见卡点。  
3. **下篇 — 深入原理**：以架构与运行机制为主，配图与少量示例，指向官方深度文档。

### 1.3 非目标

- 不在仓库内复制大段英文官方文档；以摘要 + 链接代替。  
- 不写死易随版本变化的安装命令细节；一律以官方 README / 安装页为权威，正文只保留「验证思路」与「应出现的现象」。  
- 不在学习文档中嵌入真实 API Key、Token 或私有 endpoint。

## 3. 总索引（节 1 规格）

### 3.1 必含内容

- 一句话定义 + 官方入口链接（项目站 + 开发者文档根或架构页）。  
- **读者画像**：熟悉命令行、能配置 API Key、能接受阅读英文官方文档的工程师。  
- **版本策略**：正文以「官方当前稳定版」为叙述基准；安装与 CLI 以官方仓库 README 为准；可在索引中注明「文档编写时所参考的公开版本区间」（仅作参考，不替代官方）。  
- **阅读路径**：「只想跑通」→ 只读上篇；「要改行为 / 排障 / 理解机制」→ 下篇 + 官方 Agent Loop / Architecture。

### 3.2 可选增强

- 与仓库内其他 AI 教程的「横向对比」一句（可选，避免喧宾夺主）。

## 4. 上篇《快速上手》（节 2 规格）

### 4.1 章节顺序（标题级）

1. **目标与验收**：可勾选清单（例如：进程启动成功、完成一次最小对话或最小工具调用、日志/输出符合预期）。  
2. **环境与依赖**：操作系统、运行时（Python / 容器等以官方为准）、网络与密钥管理注意点。  
3. **安装与启动**：跟随官方最短路径；附 **验证方式**（命令或 UI 现象），说明「成功长什么样」。  
4. **最小配置**：模型提供商、环境变量类别说明；**禁止**在文档中出现真实密钥。  
5. **第一条完整闭环**：从启动到产生可复现交互；**常见报错 1～2 条** + 定位方向（链到官方 troubleshooting 或下篇相关节）。  
6. **与下篇跳转表**：表格形式「现象/问题 → 下篇章节」。

### 4.2 写法约束

- 每个关键步骤后紧跟「如何确认这一步对了」。  
- 错误示例用占位符（如 `YOUR_API_KEY`），不用形似真实 key 的字符串。

## 5. 下篇《深入原理》（节 3 规格）

### 5.1 章节顺序（标题级）

1. **总览架构**：Mermaid 图展示网关、Agent 核心、记忆、工具、执行环境等关系；模块命名与边界以官方 Architecture 为准，不臆造。  
2. **Agent 循环**：感知—规划—工具调用—观察—再迭代；链到官方 Agent Loop 文档。  
3. **记忆与持久化**：解决什么问题、会话与重启后的行为、学习者需知的边界（备份/迁移一句话级 + 官方链接）。  
4. **工具与子代理**：并行与分工的直觉模型；失败、超时、重试在学习视角下的理解方式（避免堆砌内部实现文件名，除非官方文档以此组织）。  
5. **安全与自托管**：一页级威胁模型（数据落点、网络暴露面、容器/执行环境硬ening 概念）；指向官方安全相关描述。  
6. **扩展阅读**：Release notes、Issue 阅读建议、社区资源。

### 5.2 图示要求

- 至少 **一张** 总览架构 Mermaid 图；复杂流程可再增一张 Agent 循环图。  
- 图中节点使用中文标签，必要时脚注英文官方术语。

## 6. 全篇统一写法规则（节 4 规格）

- **结构**：先结论 → Mermaid 或对照表 → 最小可抄示例（命令/配置片段）→ 必要补充（限制条件、官方为准声明）。  
- **篇幅控制**：长说明用外链；正文保持可扫读。  
- **每章末尾**：**3～5 条自测问答题** + **一条下一步动手或阅读任务**。
