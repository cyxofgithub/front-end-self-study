# 模型基础概念介绍

## 一句话总结

这部分内容是在搭建 AI 入门认知框架：先理解神经网络的基本结构，再认识常见网络类型，接着过渡到 NLP 和大语言模型，最后引出 embedding 这个核心概念。

## 1. 什么是神经网络

神经网络可以理解为一种模拟人脑处理信息方式的计算模型，最基础的结构通常是：

`输入层 -> 隐藏层 -> 输出层`

-   输入层：接收原始数据。
-   隐藏层：对数据进行特征提取和计算。
-   输出层：给出最终结果，比如分类、预测或生成内容。

## 2. 常见神经网络结构

### CNN（卷积神经网络）

-   更适合处理图像这类有空间结构的数据。
-   常用于图片分类、目标检测、图像识别等任务。

### RNN（循环神经网络）

-   更适合处理有前后顺序关系的序列数据。
-   常用于文本、语音、时间序列等任务。

## 3. NLP 与大语言模型

NLP（自然语言处理）主要研究如何让计算机理解和处理人类语言。

在 NLP 的发展过程中，出现了越来越强的大语言模型，比如：

-   ChatGPT
-   DeepSeek

这类模型可以完成问答、写作、总结、翻译、代码生成等任务。

## 4. Embedding 是什么

Embedding 可以理解为“向量化表示”，也就是把文字、词语、句子等内容转换成计算机更容易处理的数字向量。

它的作用是：

-   让模型理解不同词语或句子之间的相似性。
-   为语义搜索、推荐系统、知识库检索、大模型应用提供基础能力。

## 总结

这一节的学习主线是：

神经网络基础结构 -> 常见网络类型（CNN、RNN） -> NLP -> 大语言模型 -> Embedding

也就是说，这一页的重点不是深入某一个算法，而是先建立对 AI 和大模型基础概念的整体认识。
