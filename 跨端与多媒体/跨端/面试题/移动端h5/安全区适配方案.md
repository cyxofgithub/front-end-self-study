# 移动端底部安全区适配 — 最终标准化落地方案

> 适用：H5 网页、App 内嵌 WebView、微信/支付宝小程序，一次性全量兼容 iOS + 所有安卓机型（手势条、三键虚拟键、各家定制 ROM）

---

## 一、固定分层逻辑（不可改动）

1. **viewport 强制标配**（`env()` 取值生效的前置条件）
2. **CSS 双层兜底**：原生 `env()` 真实值优先 + 手势条保底 24px
3. **底部固定组件与页面滚动内容区分开处理**（滚动内容、fixed 底部栏两套写法）
4. **安卓三键导航必须客户端配合开启沉浸式**，前端纯 CSS 无法解决三键遮挡问题（行业共识）
5. **JS 备用兜底**：极端 WebView 环境 `env()` 返回 0 时二次修正

---

## 二、第 1 层：HTML 固定头部配置

```html
<!-- viewport 必带 viewport-fit=cover，禁止缺失 -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover">
```

---

## 三、第 2 层：全局根 CSS（项目全局引入，标准固定写法）

```css
/* 兼容 iOS11 constant + 新标准 env */
:root {
  --safe-area-bottom: constant(safe-area-inset-bottom);
  --safe-area-bottom: env(safe-area-inset-bottom);
  /* 标准化兜底下限：手势热区统一 24px，抛弃 20px */
  --safe-bottom: max(var(--safe-area-bottom), 24px);
  --safe-area-top: constant(safe-area-inset-top);
  --safe-area-top: env(safe-area-inset-top);
}

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* 页面流式滚动内容全局避让，防止底部内容被遮挡 */
body {
  min-height: 100vh;
  padding-bottom: var(--safe-bottom);
}
```

## 四、第 3 层：两大业务组件标准写法（直接复制使用）

### 1）全局底部固定栏（Tab 栏、结算栏、底部操作条，最常用）

结构：外层撑满屏幕 + 内层放置按钮内容

```html
<div class="fixed-bottom">
  <div class="fixed-bottom__inner">按钮/导航</div>
</div>
```

```css
.fixed-bottom {
  position: fixed;
  left: 0;
  right: 0;
  bottom: 0;
  width: 100%;
  background: #fff;
  /* 安全区填充背景，和栏底色融为一体 */
  padding-bottom: var(--safe-area-bottom);
}
.fixed-bottom__inner {
  height: 50px;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

### 2）底部弹窗、抽屉弹窗

```css
.popup-bottom {
  position: fixed;
  left: 0;
  right: 0;
  bottom: 0;
  padding-bottom: var(--safe-area-bottom);
  border-radius: 12px 12px 0 0;
  background: #fff;
}
```

### 3）全屏沉浸式页面（活动页、落地页）

```css
.page-wrap {
  min-height: 100vh;
  background: #000;
}
.page-content {
  padding-bottom: calc(30px + var(--safe-bottom));
}
```

## 五、安卓端配套强制规则（标准化闭环，缺一不可）

### 1、App 内嵌 WebView（客户端必须实现）

```java
// 1. 允许页面绘制到系统导航栏下方
WindowCompat.setDecorFitsSystemWindows(window, false);
// 2. 导航栏透明
window.setNavigationBarColor(Color.TRANSPARENT);
// 3. WebView 配置
webView.setSystemUiVisibility(
    View.SYSTEM_UI_FLAG_LAYOUT_HIDE_NAVIGATION
    | View.SYSTEM_UI_FLAG_LAYOUT_FULLSCREEN
);
```

> 客户端不做上面配置：所有安卓三键导航下 `env()` = 0，只会触发 24px 兜底，**三键 48dp 高度依然会遮挡元素**，前端无解。

### 2、手机浏览器（Chrome、系统自带浏览器）

无需客户端配合，浏览器原生支持 `env()`，上面 CSS 自动生效。

### 3、安卓端 `env()` 生效判断总览

```
是不是手机浏览器？
  ├─ 是 → env() 直接生效，CSS 搞定
  └─ 不是（App WebView）
       ├─ 客户端开了沉浸式 + WebView 内核够新 → env() 生效
       └─ 任一条件不满足 → env() = 0，走 24px 兜底
                              ↓
                          如果还有三键导航 → 24px 不够，需客户端 JSBridge 注入真实值
```

> 核心认知：客户端开沉浸式是**必要但不充分**条件。国产 ROM 定制 WebView、微信/支付宝等超级 App 自带 WebView 内核版本往往滞后，即使开了沉浸式 `env()` 仍可能返回 0。前端能兜底的极限就是 24px。

## 六、JS 补充兜底方案（兼容老旧 WebView）

部分老旧 App 壳子 `env()` 恒为 0，用 JS 读取系统安全值覆盖 CSS 变量：

```js
const setSafeAreaVar = () => {
  const safeBottom = parseInt(getComputedStyle(document.documentElement).getPropertyValue('--safe-area-bottom')) || 0;
  const realBottom = Math.max(safeBottom, 24);
  document.documentElement.style.setProperty('--safe-bottom', `${realBottom}px`);
};
setSafeAreaVar();
window.addEventListener('resize', setSafeAreaVar);
```

## 八、精简版标准答案总结（记住 3 句话）

1. viewport 必须加 `viewport-fit=cover`；根变量用 `max(env值, 24px)` 作为全局兜底
2. 页面滚动内容靠 `body padding-bottom: var(--safe-bottom)`；fixed 底部容器只给 `padding-bottom: env原始值` 填充底色
3. 安卓 App 内嵌页面必须客户端开沉浸式，浏览器、小程序纯 CSS 即可全覆盖
