# 小程序性能监测 Demo

这是一个可直接导入微信开发者工具的原生微信小程序项目，不是 HTML 模拟页面。

## 导入运行

1. 打开微信开发者工具。
2. 选择“导入项目”，项目目录选择当前目录。
3. `AppID` 可以使用测试号或游客模式；项目配置中的 `touristappid` 仅用于本地演示。
4. 编译后，点击微信开发者工具顶部工具栏的“性能”面板；保持面板开启，再回到 Demo 页面点击“开始实验”。

## 实验步骤

### 逐事件更新

选择“逐事件更新”，设置 300 个节点、30 个事件/秒、4 KB payload。观察页面中的 `setData 更新`、`更新回调`、`nextTick 延迟` 和开发者工具性能时间线。

### 批量更新

保持参数不变，切换为“批量更新”。数据事件仍然产生，但 50ms 内会合并为一次页面更新，比较两种策略的 `setData 更新` 次数和页面响应。

### 内存趋势

勾选“模拟未释放内存”并运行一段时间，停止后点击“重置指标与内存”。在支持 `wx.getPerformance().memory` 的环境中观察 JS Heap，否则使用开发者工具或真机面板观察内存趋势。

### 长列表压力

把模拟节点调到 800，再提高数据事件频率。观察滚动、输入和页面更新是否出现延迟；然后切换为批量更新，验证减少通信次数的效果。

## 指标边界

页面内测量的是当前小程序真实发生的 `setData`、回调耗时、`wx.nextTick` 延迟和可用的 JS Heap。FPS、渲染层真实帧率、图片/Canvas 原生内存和运行时完整桥接耗时，应以微信开发者工具性能面板和低端真机结果为准。
