# pnpm 优势

## 1. 磁盘空间节省

-   使用**硬链接**和**符号链接**，所有包只存储一份在全局 store
-   不同项目共享相同版本的依赖，避免重复存储
-   相比 npm/yarn 可节省大量磁盘空间

## 2. 安装速度快

-   **并行安装**：充分利用多核 CPU
-   **更好的缓存机制**：基于内容寻址存储，避免重复下载
-   安装速度通常比 npm/yarn 快 2-3 倍

## 3. 严格的依赖管理

-   **避免幽灵依赖**：只能访问 package.json 中声明的依赖
-   通过符号链接隔离依赖，提升项目安全性
-   防止意外使用未声明的包

## 4. Monorepo 友好

-   内置 workspace 支持，配置简单
-   高效的依赖提升策略
-   更好的跨包依赖管理

## 5. 兼容性好

-   完全兼容 npm 生态系统
-   支持 package.json 和 node_modules 结构
-   可无缝替换 npm/yarn

## 6. 安全性

-   严格的依赖隔离
-   支持内容寻址存储，确保包完整性
-   更好的依赖解析机制
