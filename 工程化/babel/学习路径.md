## 第一阶段：快速上手

### 1.1 快速了解 Babel

-   [☑️] Babel 是什么：JavaScript 编译器，将新语法转换为旧语法

### 1.2 安装和第一个例子

-   [☑️] 安装核心包
    ```bash
    npm install --save-dev @babel/core @babel/cli @babel/preset-env
    ```
-   [☑️] 创建 `babel.config.js`
    ```js
    module.exports = {
        presets: ['@babel/preset-env'],
    };
    ```
-   [☑️] 编译文件：`npx babel src --out-dir dist`

**实践任务（必须完成）：**

-   创建一个包含箭头函数、const、class 的 ES6+ 文件
-   使用 Babel 编译，查看输出结果

## 第二阶段：核心配置

### 2.1 @babel/preset-env 详解

-   [☑️] **targets 配置**：指定目标浏览器
    ```js
    presets: [
        [
            '@babel/preset-env',
            {
                targets: {
                    chrome: '58',
                    ie: '11',
                },
                // 或使用 browserslist: '> 0.25%, not dead'
            },
        ],
    ];
    ```
-   [☑️] **useBuiltIns**：polyfill 处理方式
    -   `false`：不处理（默认）
    -   `'entry'`：在入口文件引入 `import 'core-js/stable'`
    -   `'usage'`：按需自动引入（推荐）
-   [☑️] **corejs 配置**：指定 core-js 版本
    ```js
    {
      useBuiltIns: 'usage',
      corejs: 3  // 需要安装 core-js@3
    }
    ```

**实践任务（必须完成）：**

-   配置支持 IE11 的 Babel
-   对比 `useBuiltIns: 'entry'` 和 `'usage'` 的打包体积差异

### 2.2 其他常用 Presets

-   [☑️] `@babel/preset-react` - React 项目
-   [☑️] `@babel/preset-typescript` - TypeScript 项目
-   [☑️] 多个 preset 的组合使用

**实践任务：**

-   在 React 项目中配置 Babel

### 2.3 Plugins 基础

-   [☑️] 插件的概念：单个语法转换
-   [☑️] 插件执行顺序：从前往后
-   [☑️] 常用插件（了解即可，preset-env 已包含大部分）：
    -   `@babel/plugin-proposal-decorators` - 装饰器
    -   `@babel/plugin-transform-runtime` - 减少重复代码

**实践任务：**

-   添加装饰器插件支持装饰器语法

### 2.4 Polyfill 配置（重点！1-2 天）

-   [ ] **方式一：useBuiltIns + core-js**（推荐）
    ```bash
    npm install --save core-js@3
    ```
    ```js
    {
      useBuiltIns: 'usage',
      corejs: 3
    }
    ```
-   [ ] **方式二：@babel/plugin-transform-runtime**（库开发推荐）
    ```bash
    npm install --save-dev @babel/plugin-transform-runtime
    npm install --save @babel/runtime
    ```

**实践任务（必须完成）：**

-   配置 Promise、async/await 的 polyfill
-   测试在旧浏览器中运行

## 第三阶段：实际应用（5-7 天）

### 3.1 与 Webpack 集成（2 天）

-   [ ] 安装 `babel-loader`
    ```bash
    npm install --save-dev babel-loader
    ```
-   [ ] Webpack 配置
    ```js
    module: {
        rules: [
            {
                test: /\.js$/,
                exclude: /node_modules/,
                use: {
                    loader: 'babel-loader',
                    options: {
                        cacheDirectory: true, // 启用缓存
                    },
                },
            },
        ];
    }
    ```

**实践任务（必须完成）：**

-   在现有 Webpack 项目中配置 Babel
-   启用缓存，对比编译速度

### 3.2 与 Vite 集成（1 天）

**实践任务：**

-   对比优化前后的编译时间

### 3.4 常见场景配置（1-2 天）

## 第四阶段：插件开发入门（可选，5-7 天）

> **说明**：如果只是使用 Babel，可以跳过此阶段。如果想深入理解或需要自定义转换，可以学习。

### 4.1 理解 AST（1-2 天）

-   [ ] AST 是什么：代码的树形结构表示
-   [ ] 使用 [AST Explorer](https://astexplorer.net/) 查看 AST
-   [ ] 理解常见节点类型：Identifier、CallExpression、ArrowFunctionExpression

**实践任务：**

-   在 AST Explorer 中输入简单代码，观察 AST 结构

### 4.2 Babel 工作流程（30 分钟）

-   [ ] Parse：代码 → AST
-   [ ] Transform：AST → AST（通过插件）
-   [ ] Generate：AST → 代码

### 4.3 编写第一个插件（2-3 天）

-   [ ] 插件基本结构
    ```js
    module.exports = function () {
        return {
            visitor: {
                Identifier(path) {
                    // 处理 Identifier 节点
                },
            },
        };
    };
    ```
-   [ ] 使用 `@babel/types` 检查节点类型
-   [ ] 修改节点

**实践任务（必须完成）：**

-   编写插件：将 `console.log` 转换为 `console.warn`
-   编写插件：移除所有 `debugger` 语句

### 4.4 常用 API（1-2 天）

-   [ ] `@babel/types` - 创建和检查节点
-   [ ] `@babel/template` - 从字符串创建 AST
-   [ ] Path API - 节点的增删改查

**实践任务：**

-   使用 `@babel/template` 生成代码片段

**学习资源：**

-   [Babel 插件手册](https://github.com/jamiebuilds/babel-handbook/blob/master/translations/zh-Hans/plugin-handbook.md)

## 快速参考：常用配置模板

### React 项目配置

```js
// babel.config.js
module.exports = {
    presets: [
        [
            '@babel/preset-env',
            {
                useBuiltIns: 'usage',
                corejs: 3,
            },
        ],
        [
            '@babel/preset-react',
            {
                runtime: 'automatic', // 新 JSX 转换
            },
        ],
    ],
};
```

### TypeScript 项目配置

```js
module.exports = {
    presets: [
        [
            '@babel/preset-env',
            {
                useBuiltIns: 'usage',
                corejs: 3,
            },
        ],
        '@babel/preset-typescript',
    ],
};
```

### 库开发配置（使用 transform-runtime）

```js
module.exports = {
    presets: [
        [
            '@babel/preset-env',
            {
                modules: false, // 保留 ES 模块
            },
        ],
    ],
    plugins: [
        [
            '@babel/plugin-transform-runtime',
            {
                corejs: false,
                helpers: true,
                regenerator: true,
            },
        ],
    ],
};
```

## 快速入门学习建议

1. **边学边用**：每学一个配置，立即在项目中实践
2. **聚焦核心**：重点掌握 `@babel/preset-env` 和 polyfill 配置
3. **遇到问题查文档**：Babel 文档很详细，遇到问题先查文档
4. **使用在线工具**：用 [Babel REPL](https://babeljs.io/repl) 快速测试配置
5. **不要过度配置**：大部分项目用 `preset-env` 就够了
6. **插件开发可选**：如果只是使用 Babel，可以跳过插件开发部分
