前端动画性能 Demo

单文件，浏览器直接打开。四个面板对应 前端动画.md 的高频题。

① transform vs left：主线程阻塞时谁还在动？

绿盒 = CSS transform 动画（合成器线程）；蓝盒 = rAF 驱动 left（主线程）。点「阻塞主线程 2s」观察差异。

T
合成器线程动画（肉眼观察流畅度）
L
主线程 rAF FPS –

预期：阻塞期间绿盒继续平滑移动（合成器线程不受影响），蓝盒冻结（rAF 回调跑在主线程被卡死）。这就是「CSS 动画为什么比 JS 动画性能好」的底层原因——线程分离。

③ will-change / 合成层

给缩放动画的元素加 will-change: transform 提前建合成层。合成层本身不可见，需开 DevTools 验证。

hover 放大盒子，肉眼无明显差异；收益在「预热合成层避免首帧卡顿」和「动画全程只走合成阶段」。验证见 README。
