## 扁平化数组的几种方式

### 1. 遍历 + 栈

```javascript
function flatten(arr) {
    const result = [];
    const stack = [...arr];

    while (stack.length) {
        const item = stack.pop();
        if (Array.isArray(item)) {
            stack.push(...item);
        // 这里使用 unshift 是往前插入元素，使最终顺序和原数组一致。
        // 若用 push 则是向后插入，最后需要 reverse 保证顺序一致。
        } else {
            result.unshift(item); // 向前插入
        }
    }

    return result;
}

// 示例
const arr = [1, [2, 3], [4, [5, 6]]];
console.log(flatten(arr)); // [1, 2, 3, 4, 5, 6]
```

**优点：**

-   非递归实现，避免栈溢出
-   性能较好，适合深度嵌套的数组
-   思路清晰，易于理解

**缺点：**

-   代码相对复杂
-   使用 `unshift` 可能影响性能（可改用 `push` + `reverse`）

### 2. reduce + 递归

```javascript
function flatten(arr) {
    return arr.reduce((prev, curr) => {
        return prev.concat(Array.isArray(curr) ? flatten(curr) : curr);
    }, []);
}

// 示例
const arr = [1, [2, 3], [4, [5, 6]]];
console.log(flatten(arr)); // [1, 2, 3, 4, 5, 6]
```

**优点：**

-   代码简洁，函数式编程风格
-   逻辑清晰，易于理解
-   使用 `concat` 不会修改原数组

**缺点：**

-   递归实现，深度嵌套可能导致栈溢出
-   性能相对较差（频繁创建新数组）
-   对于超深嵌套数组不适用

### 3. JSON.stringify + JSON.parse

```javascript
function flatten(arr) {
    const str = JSON.stringify(arr);
    return JSON.parse('[' + str.replace(/\[|\]/g, '') + ']');
}

// 或者更优雅的方式
function flatten(arr) {
    return JSON.parse('[' + JSON.stringify(arr).replace(/\[|\]/g, '') + ']');
}

// 示例
const arr = [1, [2, 3], [4, [5, 6]]];
console.log(flatten(arr)); // [1, 2, 3, 4, 5, 6]
```

**优点：**

-   代码非常简洁
-   一行代码即可实现

**缺点：**

-   只能处理数字和字符串，不能处理对象、函数等
-   性能较差（序列化和反序列化开销大）
-   不适用于复杂数据类型
-   正则替换可能有问题（如数组元素中包含 `[` 或 `]` 字符）

### 4. Array.prototype.flat()（ES2019）

```javascript
// 默认只扁平化一层
const arr = [1, [2, 3], [4, [5, 6]]];
console.log(arr.flat()); // [1, 2, 3, 4, [5, 6]]

// 扁平化所有层级
console.log(arr.flat(Infinity)); // [1, 2, 3, 4, 5, 6]
```

**优点：**

-   原生 API，使用简单
-   性能优秀（浏览器优化）
-   支持指定扁平化深度
-   不修改原数组

**缺点：**

-   需要 ES2019+ 支持
-   老版本浏览器需要 polyfill

### 5. 扩展运算符 + some() + concat()

```javascript
function flatten(arr) {
    while (arr.some((item) => Array.isArray(item))) {
        arr = [].concat(...arr);
    }
    return arr;
}

// 示例
const arr = [1, [2, 3], [4, [5, 6]]];
console.log(flatten(arr)); // [1, 2, 3, 4, 5, 6]
```

**优点：**

-   代码简洁
-   非递归实现，避免栈溢出
-   使用原生方法，性能较好

**缺点：**

-   每次循环都会创建新数组
-   对于深度嵌套数组，循环次数较多

### 6. toString() + split()

```javascript
function flatten(arr) {
    return arr
        .toString()
        .split(',')
        .map((item) => Number(item));
}

// 示例
const arr = [1, [2, 3], [4, [5, 6]]];
console.log(flatten(arr)); // [1, 2, 3, 4, 5, 6]
```

**优点：**

-   代码非常简洁
-   实现简单

**缺点：**

-   只能处理数字数组
-   会将所有元素转为字符串再转回数字，性能较差
-   不适用于其他数据类型

### 总结

| 方法          | 性能       | 适用场景            | 兼容性  |
| ------------- | ---------- | ------------------- | ------- |
| 遍历 + 栈     | ⭐⭐⭐⭐   | 深度嵌套数组        | 好      |
| reduce + 递归 | ⭐⭐       | 浅层嵌套数组        | 好      |
| JSON 方法     | ⭐         | 简单数字/字符串数组 | 好      |
| flat()        | ⭐⭐⭐⭐⭐ | 现代浏览器环境      | ES2019+ |
| 扩展运算符    | ⭐⭐⭐     | 一般场景            | ES6+    |
| toString()    | ⭐         | 纯数字数组          | 好      |

**推荐使用：**

-   现代项目：优先使用 `Array.prototype.flat(Infinity)`
-   需要兼容性：使用 `遍历 + 栈` 或 `reduce + 递归`
