## location.href 与 replace 的区别

| 特性     | location.href              | location.replace()                    |
| -------- | -------------------------- | ------------------------------------- |
| 历史记录 | 新增一条记录               | 替换当前记录                          |
| 后退按钮 | 可回到原页面               | 无法回到原页面                        |
| 使用场景 | 普通页面跳转（如导航链接） | 登录/支付后跳转、错误页跳转等无需回退 |
