## 你对 “前端工程化” 的理解是什么？它核心解决了前端开发中的哪些问题？（效率、质量、可维护性、协作）

### 前端工程化核心解决的四大问题

1. 提升开发效率：从 “重复劳动” 到 “自动化提效”

任何一切减少重复开发的事情，脚手架、自动化工具

2. 保障开发质量：从 “靠人检查” 到 “靠工具兜底”

ESLint + Prettier + TypeScript+ sentry

3. 增强可维护性：从 “面条代码” 到 “模块化架构”

模块化、组件化、规范化目录结构、分层架构设计。

4. 优化团队协作：从 “各自为战” 到 “协同一致”

Git、husky、lint-staged、敏捷开发、Docker 容器化、Mock 服务

### 前端工程化的核心落地环节

一个完整的前端工程化体系，通常包含以下环节：

1. 初始化：用 create-react-app/vue-cli/vite create 快速生成标准化项目模板；
2. 开发：模块化 / 组件化开发 + 热更新 + Mock 服务；
3. 校验：ESLint + Prettier + TypeScript 静态检查；
4. 构建：webpack/vite 打包、代码分割、性能优化；
5. 测试：单元测试 + 集成测试 + E2E 测试；
6. 部署：CI/CD 自动化部署 + 环境隔离；
7. 监控：线上错误监控（如 Sentry） + 性能监控（如 Lighthouse）。
