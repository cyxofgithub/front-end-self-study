岗位描述

1. 具备扎实的前端基础，熟练掌握 HTML、CSS、JavaScript、TypeScript，理解浏览器运行机制、网络协议及常见性能优化方法。
2. 熟练掌握 Vue 3 及相关技术生态，熟悉 Composition API、Vue Router、Pinia 等，具备复杂项目或核心模块开发经验。
3. 熟悉 Webpack、Vite 等构建工具，具备前端工程化、组件化、模块化及构建性能优化经验。
4. 具备 Node.js 开发能力，能够完成中间层服务、工程化工具、构建脚本或相关基础设施的开发。
5. 具备微信小程序或其他小程序平台的实际开发经验，熟悉小程序组件、生命周期、性能优化及平台能力。
6. 具备较强的业务理解、架构设计和独立解决问题能力，能够快速定位并处理复杂业务问题、性能问题及线上故障。
7. 具备良好的沟通表达、团队协作和项目推动能力，能够清晰传递技术方案、项目风险和研发进度。
8. 有 AI 辅助研发或 AI 应用开发经验者优先，包括使用 AI 编程工具提升研发效率，或具备大模型接入、Agent 编排、Tool Calling、MCP、RAG 等相关实践经验。

岗位职责

1. 负责公司核心 Web 应用、小程序及相关前端产品的设计、开发、维护和持续优化。
2. 深入理解业务需求，参与需求分析、技术评审和方案设计，合理评估研发成本、技术风险及实现路径。
3. 基于 Vue 3、TypeScript 等技术完成高质量编码，保障系统的可维护性、可扩展性、性能和稳定性。
4. 负责前端项目架构及核心模块建设，包括组件体系、状态管理、权限体系、路由设计、接口封装和异常处理等。
5. 推进前端工程化建设，持续优化 Webpack、Vite、代码规范、构建发布流程及研发协作效率。
6. 使用 Node.js 开发或维护中间层服务、脚手架、自动化工具及其他前端基础设施。
7. 独立分析和解决复杂技术问题，及时处理线上故障，推动问题复盘、性能优化和质量改进。
8. 参与代码评审和团队技术建设，沉淀通用组件、工具库及技术文档；结合业务场景探索 AI 辅助研发、智能应用或 Agent 工作流的落地。"
