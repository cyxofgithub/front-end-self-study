# 【岗位职责】

1. 独立负责 无人车前端核心模块的设计、开发与落地，覆盖云远平台、智拉运营后台、调度/运维端等，高质量交付复杂需求。
2. 云远与实时链路：参与/负责多路视频拉流（WebRTC / 云 RTC)、WebSocket / MQTT 等实时推送的接入、降级、重连与长时稳定性治理。
3. 地图与可视化：优化控车/监控页地图与状态可视化（轨迹、车辆状态、告警、2D/Canvas 渲染等）
4. 架构与风险：主导本方向前端技术方案，识别并推动解决内存泄漏、性能卡顿、跨端联调等风险；沉淀可复用组件与规范。
5. 跨端协作：与产品、后端、车端/座舱、测试高效对齐，推动联调窗口落地；有 owner 意识，能主动暴露风险并闭环。
6. 提炼提效方案，参与技术分享与知识库建设；必要时主导局部技术改造与工程化改进。

# 【任职要求】

## 基础与经验

- 本科及以上学历，3～5 年及以上 前端开发经验；有主导中大型项目架构经验者优先
- HTML / CSS / JavaScript 基础扎实；精通 TypeScript
- 深入理解至少一种主流框架（Vue / React)，有大中型 中后台或实时交互类 项目经验
- 熟悉前端工程化（Vite / Webpack 等），关注可维护性、质量与性能

## 业务技术深度

- 实时视频：了解 WebRTC 拉流原理（断线恢复、多路并发解码压力等），有直播/监控/会议类经验优先
- 实时消息：熟悉 WebSocket / MQTT（或同类长连接），理解心跳、重连退避、订阅生命周期、消息幂等问题
- 地图与渲染：有高德/百度等地图 SDK、Canvas / WebGL 可视化、高频数据更新优化经验优先
- 了解 HTTP/HTTPS、浏览器运行时原理；能独立排查网络、内存、渲染类线上问题

## AI 与效率

- 积极拥抱 AI：能正确使用 AI 辅助编程（Cursor / Copilot 等）提升交付效率
- 理解 AI 的能力边界：保证效率及线上质量

## 协作与解决问题方式

- 思维敏捷：能快速抓住问题核心，拆解方案并推动落地，表达直接
- 沟通清晰：跨部门协作，能与产品、后端、车端等上下游对齐并达成共识

# 【加分项】

- 自动驾驶 / 物流 / IoT / 工业监控 / 远程操控等行业经验
- 有长时运行系统治理经验（内存泄漏排查、连续数小时稳定性压测、关键性能指标对比）
- WebGL / Three.js、多屏座舱、GamePad / 外设接入等经验
- 主导过老旧系统改造、前端规范建设或组件库贡献
- 有开源作品或技术博客（附链接）
