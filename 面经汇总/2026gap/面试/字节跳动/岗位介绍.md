# Node.js 研发工程师 - 飞书（BOSS直聘）

## 职位描述

1、参与飞书文档Node.js服务的设计、开发和维护，支撑文档、幻灯片等产品的稳定迭代；
2、参与SSR、PageServer、静态页面运行时及灰度策略等服务能力建设；
3、负责HTTP/RPC接口、任务编排、缓存和上下游依赖的开发，保证接口语义、兼容性和异常降级行为；
4、参与Node.js服务性能优化，解决CPU、内存、事件循环阻塞、Worker调度及高并发场景下的性能问题；
5、建设和完善单元测试、集成测试、CI/CD、监控、告警、限流、灰度及故障止损能力，参与线上问题排查和服务治理，通过日志、指标、调用链和运行时数据定位根因并推动解决；
6、使用AI Coding工具辅助需求分析、代码开发、测试生成、代码评审和问题定位，持续提升研发效率与交付质量。

## 职位要求

1、本科及以上学历，计算机相关专业优先，具备扎实的计算机基础；
2、熟练掌握 JavaScript/TypeScript，能够使用 Node.js 完成结构清晰、可测试、可维护的服务端开发；
3、理解 Node.js 事件循环、异步编程、异常处理、内存管理及常见性能问题；
4、熟悉 HTTP、RPC、网络通信等基础知识，具备服务端接口开发或维护经验；
5、具备良好的工程质量意识，能够编写单元测试和集成测试，熟悉 Git、CI/CD及常见工程化工具；
6、具备基本的线上问题排查能力，能够结合日志、监控指标和调用链分析服务异常；
7、具备良好的沟通协作能力，能够快速理解陌生业务和已有系统，并持续推进问题解决；
8、熟练使用至少一种 AI Coding 工具，能够合理验证AI 生成代码的正确性、兼容性和安全性；
9、关注大模型、AIGC 和 AI 工程化趋势，对 AI 与内容创作工具结合有兴趣。

## 加分项

1、有 SSR、BFF、Node.js RPC 服务或高并发后端服务开发经验；
2、熟悉 V8、Heap Snapshot、CPU Profile、Worker Threads、Child Process 等 Node.js 运行时能力；
3、有浏览器端复杂应用或前端基础设施经验，能够理解前后端共享代码和同构运行场景；
4、熟悉 MySQL、Redis、缓存、消息队列、配置中心或服务治理体系；
5、有灰度发布、多地域部署、限流降级、稳定性建设或线上 Oncall 经验。
