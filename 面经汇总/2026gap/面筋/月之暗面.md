# 月亮之暗面

## 二面

### AI 聊天界面的流式文本渲染（Stream Rendering）容易导致页面卡顿，你有哪些性能优化手段？

1. dom 写入优化：setTimeout 80ms 收齐一堆零碎 chunk → 合并成一段文本 → 用 Fragment 在内存拼装所有元素 -> rAF 对齐屏幕帧一次性更新 DOM

2. 渲染层：减少回流重绘

```css
.ai-stream-wrapper {
    min-height: 100px;
    max-height: 70vh;
    overflow-y: auto;
    /* 给消息容器设置 contain: layout paint size，将容器划为独立渲染区域，内部文本高度变化只会触发局部回流，不会引起整个页面布局重算 */
    contain: layout paint size;
    /* 搭配 will-change 提前告知浏览器内容会频繁更新，预分配渲染资源； */
    will-change: contents;
    /* 升起独立 GPU 合成层，绘制操作交由 GPU 处理，降低主线程重绘压力 */
    transform: translateZ(0);
}
```

3. 主线程减负，解决掉帧卡顿
    - 流二进制解码、数据清洗丢入WebWorker，把耗时运算移出主线程
    - 滚动、Resize 等高频事件统一节流防抖
