## vue3 响应式原理

我觉得要理解 vue 响应式原理可以从 vue 中的 watch api 出发，我们在 watch 一个数据的时候会传入，要监听的数据，还有一个回调，其实这个过程是调用了 vue 中 new reactiveEffect 的一个过程，会传进我们定义 watch 数据时的getter和callback，然后会主动调用 getter 去触发收集当前callback，当状态变化时就可以调用这个effect触发callback执行
