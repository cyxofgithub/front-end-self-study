# 2.1 Android Studio 与真机调试

> 搭建开发环境，学会真机调试和 adb 命令。

---

## 一、Android Studio 安装与配置

### 安装步骤

1. 下载：https://developer.android.com/studio
2. 安装后打开，进入 **SDK Manager**（设置 → Appearance & Behavior → System Settings → Android SDK）
3. 下载必要组件：
   - Android SDK Platform（推荐 API 33/34）
   - Android SDK Build-Tools
   - Android SDK Platform-Tools（包含 adb）
   - Android Emulator（如需模拟器）

### 关键配置

**SDK 版本**：
```
项目级 build.gradle:
compileSdk = 34       // 编译用的 SDK 版本
minSdk = 24           // 最低支持的 Android 版本
targetSdk = 34        // 目标 SDK 版本（影响系统行为）
```

**JDK 版本**：
```
推荐 JDK 17（Android Gradle Plugin 8.x 要求）
File → Project Structure → SDK Location → JDK location
```

**Gradle 版本**：
```
gradle-wrapper.properties:
distributionUrl=https\://services.gradle.org/distributions/gradle-8.0-bin.zip
```

### 常用快捷键

| 操作 | Mac | Windows/Linux |
|------|-----|---------------|
| 代码补全 | `Ctrl + Space` | `Ctrl + Space` |
| 跳转到定义 | `Cmd + B` / `Cmd + Click` | `Ctrl + B` / `Ctrl + Click` |

## 二、真机调试

### 开启开发者选项

1. 手机进入 **设置 → 关于手机**
2. 连续点击 **版本号** 7 次
3. 返回设置，出现 **开发者选项**
4. 开启 **USB 调试**

### USB 连接

1. 用 USB 线连接手机和电脑
2. 手机上弹出授权对话框，点击**允许**
3. Android Studio 工具栏选择你的设备
4. 点击运行按钮（绿色三角）

### 无线调试（Android 11+）

```
设置 → 开发者选项 → 无线调试 → 配对设备

# 或通过 adb 命令
adb tcpip 5555
adb connect <手机IP>:5555
```

## 三、adb 常用命令

adb（Android Debug Bridge）是 Android 调试的核心工具。

### 设备管理

```bash
adb devices                    # 列出已连接设备
adb -s <serial> <command>      # 指定设备执行命令
adb kill-server                # 停止 adb 服务
adb start-server               # 启动 adb 服务
```

### 应用操作

```bash
adb install app.apk            # 安装 APK
adb install -r app.apk         # 覆盖安装（保留数据）
adb uninstall com.example.app  # 卸载应用
adb shell am start -n com.example/.MainActivity  # 启动 Activity
adb shell am force-stop com.example.app          # 强制停止应用
```

### 文件操作

```bash
adb push local.txt /sdcard/    # 电脑 → 手机
adb pull /sdcard/file.txt ./   # 手机 → 电脑
adb shell ls /sdcard/          # 列出手机目录
```

### 日志

```bash
adb logcat                     # 实时日志
adb logcat -s TAG:V            # 只看指定 TAG 的日志
adb logcat *:E                 # 只看 Error 级别
adb logcat | grep "keyword"    # 过滤关键字
adb logcat -d > log.txt        # 导出日志到文件
```

### 截图与录屏

```bash
adb shell screencap /sdcard/screenshot.png    # 截图
adb pull /sdcard/screenshot.png               # 拉取截图
adb shell screenrecord /sdcard/recording.mp4  # 录屏（最长 3 分钟）
```

### 其他

```bash
adb shell dumpsys battery       # 查看电池信息
adb shell dumpsys meminfo com.example.app  # 查看应用内存
adb shell wm density            # 查看屏幕密度
adb shell wm size               # 查看屏幕分辨率
adb reboot                      # 重启设备
```

## 四、打包构建

### Debug 包

```bash
# 命令行
./gradlew assembleDebug

# 输出路径
app/build/outputs/apk/debug/app-debug.apk
```

Debug 包特点：
- 使用默认 debug 签名
- 包含调试信息
- 可以直接安装调试

### Release 包

```bash
# 命令行
./gradlew assembleRelease

# 输出路径
app/build/outputs/apk/release/app-release.apk
```

### 签名配置

```groovy
// app/build.gradle
android {
    signingConfigs {
        debug {
            // 默认 debug 签名，自动生成
        }
        release {
            storeFile file("release.jks")      // 密钥库文件
            storePassword "store_password"      // 密钥库密码
            keyAlias "key_alias"               // 密钥别名
            keyPassword "key_password"          // 密钥密码
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true                  // 代码混淆
            shrinkResources true                // 资源压缩
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
}
```

### Build Variants

Android Studio 左下角 → Build Variants，可切换：

| Variant | 说明 |
|---------|------|
| debug | 开发调试版本 |
| release | 正式发布版本 |

## 五、Gradle 依赖管理

### 依赖配置类型

```groovy
dependencies {
    // implementation — 最常用，编译+打包
    implementation 'androidx.appcompat:appcompat:1.6.1'

    // api — 传递依赖（子模块也能用）
    api project(':common')

    // compileOnly — 只编译不打包
    compileOnly 'org.projectlombok:lombok:1.18.20'

    // runtimeOnly — 只打包不编译
    runtimeOnly 'com.squareup.leakcanary:leakcanary-android:2.12'

    // testImplementation — 测试专用
    testImplementation 'junit:junit:4.13.2'
    androidTestImplementation 'androidx.test.ext:junit:1.1.5'
}
```

### 前端类比

```
Gradle 依赖                npm / pnpm
───────────                ──────────
implementation         ≈   dependencies
compileOnly            ≈   devDependencies
api                    ≈   被其他 workspace 包引用的公共依赖
testImplementation     ≈   devDependencies（测试工具）
implementation project ≈   workspace:* 引用本地包
```

### 版本管理

```groovy
// 方式 1：直接指定版本
implementation 'androidx.appcompat:appcompat:1.6.1'

// 方式 2：使用变量（推荐，统一管理）
ext {
    appcompat_version = '1.6.1'
    material_version = '1.9.0'
}
implementation "androidx.appcompat:appcompat:$appcompat_version"
implementation "com.google.android.material:material:$material_version"

// 方式 3：Version Catalog（新方式，推荐）
// gradle/libs.versions.toml
[versions]
appcompat = "1.6.1"

[libraries]
appcompat = { module = "androidx.appcompat:appcompat", version.ref = "appcompat" }

// build.gradle
implementation libs.appcompat
```

## 六、项目结构认知

### 典型 Android 项目结构

```
MyApp/
├── app/                      → 主模块（主壳工程）
│   ├── src/
│   │   ├── main/
│   │   │   ├── java/         → Java/Kotlin 源码
│   │   │   ├── res/          → 资源文件
│   │   │   └── AndroidManifest.xml  → 清单文件
│   │   ├── debug/            → Debug 构建变体
│   │   └── release/          → Release 构建变体
│   └── build.gradle          → 模块级构建配置
│
├── build.gradle              → 项目级构建配置
├── settings.gradle           → 包含的模块
├── gradle.properties         → 全局 Gradle 属性
└── gradle/
    └── wrapper/
        └── gradle-wrapper.properties  → Gradle 版本
```

### 多模块项目

```
FanxingApp/
├── app/                      → 主壳工程
├── common/                   → 公共基础库
│   ├── common-ui/            → UI 组件
│   ├── common-network/       → 网络能力
│   └── common-utils/         → 工具类
├── feature-home/             → 首页模块
├── feature-player/           → 播放器模块
├── feature-user/             → 用户模块
└── build-logic/              → 构建逻辑（Convention Plugins）
```

> **前端类比**：多模块项目 ≈ pnpm monorepo，每个模块 ≈ 一个 package，`settings.gradle` ≈ `pnpm-workspace.yaml`。
