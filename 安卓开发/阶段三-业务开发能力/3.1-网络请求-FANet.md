# 3.1 网络请求（FANet 基础）

> 掌握 FANet 网络库的同步/异步请求和错误处理。

---

## 一、FANet 概述

FANet 是团队内部封装的网络请求库，基于 OkHttp/Retrofit 封装，提供了统一的请求和响应处理。

### 前端类比

```
FANet                      前端
──────                     ────
FANet.get()            ≈   axios.get()
FANet.post()           ≈   axios.post()
.enqueue()             ≈   .then() 异步回调
.execute()             ≈   await 同步等待
BaseResponse<T>        ≈   axios 拦截器中的统一响应结构
```

## 二、同步请求

同步请求会阻塞当前线程，**必须在子线程中执行**：

```kotlin
Thread {
    try {
        val response = FANet.get("https://api.example.com/user/info")
            .addParam("id", "123")
            .execute(UserResponse::class.java)

        // response 就是解析后的数据对象
        val user = response.data

        // 切到主线程更新 UI
        handler.post {
            showUserInfo(user)
        }
    } catch (e: Exception) {
        // 错误处理
        e.printStackTrace()
    }
}.start()
```

### 用协程替代（推荐）

```kotlin
viewModelScope.launch {
    try {
        val response = withContext(Dispatchers.IO) {
            FANet.get("https://api.example.com/user/info")
                .addParam("id", "123")
                .execute(UserResponse::class.java)
        }
        // 自动回到主线程
        showUserInfo(response.data)
    } catch (e: Exception) {
        showError(e.message)
    }
}
```

## 三、异步请求

异步请求自动在子线程执行，回调在主线程：

```kotlin
FANet.get("https://api.example.com/user/info")
    .addParam("id", "123")
    .enqueue(object : Callback<UserResponse> {
        override fun onSuccess(response: UserResponse) {
            // 主线程回调，可直接更新 UI
            showUserInfo(response)
        }

        override fun onFailure(error: Throwable) {
            // 错误回调，也是主线程
            showError(error.message)
        }
    })
```

### POST 请求

```kotlin
FANet.post("https://api.example.com/user/update")
    .addParam("name", "张三")
    .addParam("age", "25")
    .addHeader("Authorization", "Bearer $token")
    .enqueue(object : Callback<BaseResponse> {
        override fun onSuccess(response: BaseResponse) {
            Toast.makeText(context, "更新成功", Toast.LENGTH_SHORT).show()
        }

        override fun onFailure(error: Throwable) {
            Toast.makeText(context, "更新失败: ${error.message}", Toast.LENGTH_SHORT).show()
        }
    })
```

### 上传 JSON Body

```kotlin
val requestBody = JSONObject().apply {
    put("name", "张三")
    put("age", 25)
}

FANet.post("https://api.example.com/user/create")
    .setBody(requestBody.toString())
    .setContentType("application/json")
    .enqueue(object : Callback<BaseResponse> {
        override fun onSuccess(response: BaseResponse) { /* ... */ }
        override fun onFailure(error: Throwable) { /* ... */ }
    })
```

## 四、错误处理

### 通用错误处理模式

```kotlin
fun <T> request(
    call: () -> BaseResponse<T>,
    onSuccess: (T) -> Unit,
    onError: (String) -> Unit
) {
    viewModelScope.launch {
        try {
            val response = withContext(Dispatchers.IO) { call() }
            if (response.code == 0) {
                response.data?.let { onSuccess(it) }
            } else {
                onError(response.message ?: "未知错误")
            }
        } catch (e: IOException) {
            onError("网络连接失败")
        } catch (e: JSONException) {
            onError("数据解析错误")
        } catch (e: Exception) {
            onError(e.message ?: "未知错误")
        }
    }
}
```

### 统一错误类型

| 错误类型 | 说明 | 处理方式 |
|----------|------|----------|
| `IOException` | 网络不可用/超时 | 提示用户检查网络 |
| `SocketTimeoutException` | 请求超时 | 重试或提示 |
| `JSONException` | 数据解析错误 | 上报 Bug |
| `HttpException` | 服务器错误（404/500 等） | 根据状态码处理 |
| `token 过期` | 401 未授权 | 跳转登录页 |
| `业务错误` | code != 0 | 显示后端返回的错误信息 |

## 五、接口定义模式

### BaseResponse 包装

```kotlin
// 通用响应结构
data class BaseResponse<T>(
    val code: Int,        // 0 = 成功，非 0 = 业务错误
    val message: String?, // 错误信息
    val data: T?          // 业务数据
) {
    val isSuccess: Boolean get() = code == 0
}
```

### Data 类定义

```kotlin
// 用户信息
data class UserInfo(
    val id: String,
    val name: String,
    val avatar: String,
    val level: Int,
    val isVip: Boolean
)

// 歌曲信息
data class Song(
    val id: String,
    val title: String,
    val artist: String,
    val coverUrl: String,
    val duration: Int,       // 秒
    val playUrl: String
)

// 首页推荐列表
data class RecommendResponse(
    val bannerList: List<Banner>,
    val hotSongs: List<Song>,
    val playlists: List<Playlist>
)
```

### 分页接口

```kotlin
// 分页请求参数
data class PageRequest(
    val page: Int,           // 页码，从 1 开始
    val size: Int = 20       // 每页数量
)

// 分页响应
data class PageResponse<T>(
    val list: List<T>,       // 数据列表
    val page: Int,           // 当前页码
    val size: Int,           // 每页数量
    val total: Int,          // 总数量
    val hasMore: Boolean     // 是否还有更多数据
)
```

## 六、网络图片加载

### Glide（最常用）

```kotlin
// 基本用法
Glide.with(context)
    .load("https://example.com/photo.jpg")
    .into(imageView)

// 完整用法
Glide.with(context)
    .load(imageUrl)
    .placeholder(R.drawable.placeholder)    // 加载中占位图
    .error(R.drawable.error)                // 加载失败图
    .diskCacheStrategy(DiskCacheStrategy.ALL)  // 缓存策略
    .transform(CircleCrop())                // 圆形裁剪
    .override(200, 200)                     // 指定大小
    .into(imageView)

// 加载 GIF
Glide.with(context)
    .load(gifUrl)
    .asGif()
    .into(imageView)
```

### Coil（Kotlin 优先，推荐）

```kotlin
// 基本用法
imageView.load("https://example.com/photo.jpg")

// 完整用法
imageView.load(imageUrl) {
    placeholder(R.drawable.placeholder)
    error(R.drawable.error)
    transformations(CircleCropTransformation())
    size(200, 200)
    // 支持生命周期自动取消请求
    lifecycle(viewLifecycleOwner)
}

// 带 Listener
imageView.load(imageUrl) {
    listener(
        onStart = { showLoading() },
        onSuccess = { _, _ -> hideLoading() },
        onError = { _, _ -> showError() }
    )
}
```

### 第 4 题

```kotlin
class PagedViewModel : ViewModel() {
    private var currentPage = 1
    private var hasMore = true

    private val _items = MutableStateFlow<List<Song>>(emptyList())
    val items: StateFlow<List<Song>> = _items.asStateFlow()

    private val _isLoading = MutableStateFlow(false)
    val isLoading: StateFlow<Boolean> = _isLoading

    fun loadNextPage() {
        if (_isLoading.value || !hasMore) return
        _isLoading.value = true

        viewModelScope.launch {
            try {
                val response = withContext(Dispatchers.IO) {
                    FANet.get("https://api.example.com/songs")
                        .addParam("page", currentPage.toString())
                        .addParam("size", "20")
                        .execute(PageResponse<Song>::class.java)
                }
                hasMore = response.hasMore
                currentPage++
                _items.value = _items.value + response.list
            } catch (e: Exception) {
                println("加载失败: ${e.message}")
            } finally {
                _isLoading.value = false
            }
        }
    }
}

// RecyclerView 滑动监听
recyclerView.addOnScrollListener(object : RecyclerView.OnScrollListener() {
    override fun onScrolled(rv: RecyclerView, dx: Int, dy: Int) {
        super.onScrolled(rv, dx, dy)
        val layoutManager = rv.layoutManager as LinearLayoutManager
        if (layoutManager.findLastVisibleItemPosition() == adapter.itemCount - 1) {
            viewModel.loadNextPage()
        }
    }
})
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| FANet 同步请求 | `execute()` 阻塞线程，必须在子线程执行 |
| FANet 异步请求 | `enqueue()` 自动子线程执行，回调在主线程 |
| POST 请求 | `.post(url)` + `addParam` / `setBody` + JSON |
| BaseResponse | 统一响应结构：code/message/data；code=0 成功 |
| 错误处理 | IOException（网络）/ JSONException（解析）/ HttpException（服务器） |
| Glide 加载图片 | `load` + `placeholder` + `error` + `transform`；Coil 更 Kotlin 风格 |
| 分页加载 | 维护 page/hasMore 状态；RecyclerView 滚动监听触发加载 |
