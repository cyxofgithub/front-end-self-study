# 3.3 MVVM 与架构模式

> 掌握 MVVM、MVP 和单例模式在 Android 项目中的应用。

## 一、MVVM 模式（推荐）

### 架构图

```
┌─────────────────────────────────────────────────┐
│                    View                          │
│         Activity / Fragment / XML                │
│           （显示数据、用户交互）                    │
│                      │                           │
│              观察 LiveData/StateFlow             │
│                      │                           │
│                      ▼                           │
│                  ViewModel                       │
│        （业务逻辑、持有 UI 状态）                   │
│                      │                           │
│                  调用 Repository                  │
│                      │                           │
│                      ▼                           │
│                 Repository                       │
│         （数据源管理、缓存策略）                    │
│                  │       │                       │
│                  ▼       ▼                       │
│            Network    Database                   │
│          （网络数据）  （本地数据）                  │
└─────────────────────────────────────────────────┘
```

### 前端类比

```
MVVM                       React / Vue
────                       ──────────
View                   ≈   组件 JSX / template
ViewModel              ≈   自定义 Hook / Store (Zustand/Redux)
Repository             ≈   API 层 / 数据服务
LiveData/StateFlow     ≈   useState / useSelector
Data Binding           ≈   响应式绑定
```

### 完整示例

#### 1. Model 层（数据定义 + Repository）

```kotlin
// 数据模型
data class User(
    val id: String,
    val name: String,
    val avatar: String
)

// 接口响应
data class UserResponse(
    val code: Int,
    val data: User?
)

// Repository — 数据源管理
class UserRepository(private val api: ApiService) {

    // 内存缓存
    private var cachedUser: User? = null

    suspend fun getUser(forceRefresh: Boolean = false): Result<User> {
        // 优先使用缓存
        if (!forceRefresh && cachedUser != null) {
            return Result.success(cachedUser!!)
        }

        return try {
            val response = api.getUser()
            if (response.code == 0 && response.data != null) {
                cachedUser = response.data
                Result.success(response.data)
            } else {
                Result.failure(Exception(response.message ?: "获取失败"))
            }
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}
```

#### 2. ViewModel 层

```kotlin
// UI 状态
sealed class UserUiState {
    object Loading : UserUiState()
    data class Success(val user: User) : UserUiState()
    data class Error(val message: String) : UserUiState()
}

class UserViewModel(private val repository: UserRepository) : ViewModel() {

    private val _uiState = MutableStateFlow<UserUiState>(UserUiState.Loading)
    val uiState: StateFlow<UserUiState> = _uiState.asStateFlow()

    // 加载用户数据
    fun loadUser(forceRefresh: Boolean = false) {
        viewModelScope.launch {
            _uiState.value = UserUiState.Loading
            repository.getUser(forceRefresh)
                .onSuccess { _uiState.value = UserUiState.Success(it) }
                .onFailure { _uiState.value = UserUiState.Error(it.message ?: "未知错误") }
        }
    }

    // 刷新
    fun refresh() = loadUser(forceRefresh = true)
}

// ViewModel 工厂（用于带参数的 ViewModel）
class UserViewModelFactory(
    private val repository: UserRepository
) : ViewModelProvider.Factory {
    override fun <T : ViewModel> create(modelClass: Class<T>): T {
        return UserViewModel(repository) as T
    }
}
```

#### 3. View 层（Activity/Fragment）

```kotlin
class UserFragment : Fragment() {
    private val viewModel: UserViewModel by viewModels {
        UserViewModelFactory(UserRepository(ApiService.create()))
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        // 观察状态变化
        viewLifecycleOwner.lifecycleScope.launch {
            viewModel.uiState.collect { state ->
                when (state) {
                    is UserUiState.Loading -> {
                        progressBar.isVisible = true
                        errorText.isVisible = false
                    }
                    is UserUiState.Success -> {
                        progressBar.isVisible = false
                        nameText.text = state.user.name
                        Glide.with(this@UserFragment)
                            .load(state.user.avatar)
                            .into(avatarImage)
                    }
                    is UserUiState.Error -> {
                        progressBar.isVisible = false
                        errorText.text = state.message
                        errorText.isVisible = true
                    }
                }
            }
        }

        // 触发加载
        swipeRefreshLayout.setOnRefreshListener {
            viewModel.refresh()
        }

        viewModel.loadUser()
    }
}
```

## 二、MVP 模式

### 架构图

```
View ←───── Presenter ─────→ Model
 │            ↑                │
 │     通过接口通信              │
 │            │                │
 └── 接口回调 ─┘                │
```

### 与 MVVM 的区别

| 对比 | MVVM | MVP |
|------|------|-----|
| 数据绑定 | 观察者模式（LiveData/Flow） | 接口回调 |
| View 持有 | ViewModel 引用 | Presenter 接口引用 |
| 测试性 | 更好（ViewModel 不依赖 View） | 需要模拟 View 接口 |
| 生命周期 | ViewModel 自动管理 | 需要手动处理 |
| 推荐度 | ★★★★★ | ★★★ |

### MVP 示例

```kotlin
// View 接口
interface UserContract {
    interface View {
        fun showLoading()
        fun showUser(user: User)
        fun showError(message: String)
    }

    interface Presenter {
        fun loadUser()
    }
}

// Presenter 实现
class UserPresenter(
    private val view: UserContract.View,
    private val repository: UserRepository
) : UserContract.Presenter {

    override fun loadUser() {
        view.showLoading()
        viewModelScope.launch {
            repository.getUser()
                .onSuccess { view.showUser(it) }
                .onFailure { view.showError(it.message ?: "错误") }
        }
    }
}

// Activity 实现 View 接口
class UserActivity : AppCompatActivity(), UserContract.View {
    private val presenter = UserPresenter(this, UserRepository())

    override fun showLoading() { progressBar.isVisible = true }
    override fun showUser(user: User) { nameText.text = user.name }
    override fun showError(message: String) { errorText.text = message }
}
```

## 三、单例模式

### Kotlin object（推荐）

```kotlin
// 最简单的单例
object UserManager {
    private var currentUser: User? = null

    fun login(user: User) {
        currentUser = user
    }

    fun logout() {
        currentUser = null
    }

    fun getUser(): User? = currentUser

    fun isLoggedIn(): Boolean = currentUser != null
}

// 使用
UserManager.login(user)
val name = UserManager.getUser()?.name
```

### 伴生对象单例

```kotlin
class DatabaseHelper private constructor(private val context: Context) {

    companion object {
        @Volatile
        private var instance: DatabaseHelper? = null

        fun getInstance(context: Context): DatabaseHelper {
            return instance ?: synchronized(this) {
                instance ?: DatabaseHelper(context.applicationContext).also {
                    instance = it
                }
            }
        }
    }

    fun getDatabase(): SQLiteDatabase { /* ... */ }
}

// 使用
val db = DatabaseHelper.getInstance(context)
```

### by lazy 单例

```kotlin
class CrashReporter private constructor() {

    companion object {
        val instance: CrashReporter by lazy { CrashReporter() }
    }

    fun report(throwable: Throwable) { /* ... */ }
}

// 使用
CrashReporter.instance.report(exception)
```

## 四、ViewModel 在项目中的最佳实践

```kotlin
// 使用 Hilt/Dagger 注入（推荐）
@HiltViewModel
class HomeViewModel @Inject constructor(
    private val repository: HomeRepository
) : ViewModel() {

    private val _state = MutableStateFlow(HomeUiState())
    val state: StateFlow<HomeUiState> = _state

    init {
        loadData()
    }

    private fun loadData() {
        viewModelScope.launch {
            _state.update { it.copy(isLoading = true) }
            repository.getHomeData()
                .onSuccess { data ->
                    _state.update { it.copy(isLoading = false, data = data) }
                }
                .onFailure { error ->
                    _state.update { it.copy(isLoading = false, error = error.message) }
                }
        }
    }
}

class HomeFragment : Fragment() {

        viewLifecycleOwner.lifecycleScope.launch {
            viewModel.state.collect { state ->
                // 更新 UI
            }
        }
    }
}
```

### 第 1 题

```kotlin
// Model — 数据类
data class User(val id: String, val name: String, val avatar: String)

// Repository — 数据层
class UserRepository {
    suspend fun getUsers(): Result<List<User>> {
        return try {
            val response = withContext(Dispatchers.IO) {
                FANet.get("https://api.example.com/users")
                    .execute(BaseResponse<List<User>>::class.java)
            }
            if (response.isSuccess && response.data != null) {
                Result.success(response.data)
            } else {
                Result.failure(Exception(response.message))
            }
        } catch (e: Exception) {
            Result.failure(e)
        }
    }
}

// ViewModel — 业务逻辑
class UserListViewModel : ViewModel() {
    private val repository = UserRepository()

    private val _users = MutableStateFlow<List<User>>(emptyList())
    val users: StateFlow<List<User>> = _users.asStateFlow()

    private val _isLoading = MutableStateFlow(false)
    val isLoading: StateFlow<Boolean> = _isLoading

    fun loadUsers() {
        viewModelScope.launch {
            _isLoading.value = true
            repository.getUsers()
                .onSuccess { _users.value = it }
                .onFailure { println("加载失败: ${it.message}") }
            _isLoading.value = false
        }
    }
}

// View — Fragment
class UserListFragment : Fragment() {
    private val viewModel: UserListViewModel by viewModels()
    private lateinit var adapter: UserAdapter

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        adapter = UserAdapter()
        recyclerView.adapter = adapter

        viewLifecycleOwner.lifecycleScope.launch {
            viewModel.users.collect { users ->
                adapter.submitList(users)
            }
        }
        viewModel.loadUsers()
    }
}
```

```kotlin
sealed class UiState<out T> {
    object Loading : UiState<Nothing>()
    data class Success<T>(val data: T) : UiState<T>()
    data class Error(val message: String) : UiState<Nothing>()
}

class UserViewModel : ViewModel() {
    private val _state = MutableStateFlow<UiState<List<User>>>(UiState.Loading)
    val state: StateFlow<UiState<List<User>>> = _state.asStateFlow()

    fun loadUsers() {
        viewModelScope.launch {
            _state.value = UiState.Loading
            try {
                val users = withContext(Dispatchers.IO) { fetchUsers() }
                _state.value = UiState.Success(users)
            } catch (e: Exception) {
                _state.value = UiState.Error(e.message ?: "未知错误")

        }
    }
}

viewLifecycleOwner.lifecycleScope.launch {

                progressBar.isVisible = false

}
```

```kotlin
object ToastHelper {
    private var toast: Toast? = null

    fun show(context: Context, message: String, duration: Int = Toast.LENGTH_SHORT) {
        toast?.cancel()
        toast = Toast.makeText(context.applicationContext, message, duration).also {

        show(context, message, Toast.LENGTH_LONG)
```

### 第 4 题

```kotlin
class UserRepository(private val api: ApiService) {
    private var cachedUsers: List<User>? = null

    suspend fun getUsers(): List<User> {
        // 先返回缓存
        cachedUsers?.let { return it }

        // 缓存不存在则请求网络
        return fetchFromNetwork()
    }

    suspend fun refreshUsers(): List<User> {
        // 强制刷新
        return fetchFromNetwork()
    }

    private suspend fun fetchFromNetwork(): List<User> {
        val response = withContext(Dispatchers.IO) { api.getUsers() }
        val users = response.data ?: emptyList()
        cachedUsers = users  // 更新缓存
        return users
    }
}
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| MVVM 架构 | View → ViewModel → Repository → Network/DB；单向数据流 |
| View 层 | Activity/Fragment；观察 ViewModel 状态更新 UI |
| ViewModel | 持有 UI 状态；不持有 View 引用；生命周期比 Activity 长 |
| Repository | 管理数据源（网络/本地/缓存）；对 ViewModel 屏蔽数据来源细节 |
| Sealed Class 管理状态 | `Loading`/`Success`/`Error`；配合 `when` 强制穷举 |
| MVP vs MVVM | MVP 用接口回调；MVVM 用观察者模式（LiveData/Flow） |
| 单例模式 | `object` 声明最简单；`companion object + lazy` 延迟初始化 |
| 最佳实践 | Hilt 注入 ViewModel；StateFlow 替代 LiveData；Repository 管理缓存 |
