# 1.11 Kotlin 高级特性（Sealed Class 与委托）

> 掌握 Sealed Class（密封类）和委托（by）这两个 Kotlin 独有的强大特性。

---

## 一、Sealed Class（密封类）

### 什么是 Sealed Class？

密封类限制类的继承层级——**所有子类必须定义在同一个文件中**（Kotlin 1.5+ 可以在不同文件但在同一个包下）。它用来表示**有限的状态集合**。

```kotlin
sealed class UiState {
    // 所有子类定义在这里
    object Loading : UiState()                          // 无数据状态
    data class Success(val data: String) : UiState()    // 带数据状态
    data class Error(val message: String) : UiState()   // 带错误信息
}
```

### 配合 when 使用（编译器强制穷举）

```kotlin
fun render(state: UiState) {
    // when 必须覆盖所有分支，否则编译错误
    // 不需要 else 分支
    when (state) {
        is UiState.Loading -> showLoading()
        is UiState.Success -> showData(state.data)
        is UiState.Error -> showError(state.message)
    }
}
```

> 这就是密封类最大的好处：**编译器保证你处理了所有情况**，新增子类时编译器会报错提醒你。

### 前端类比

```typescript
// TypeScript 的可辨识联合（Discriminated Union）
type UiState =
    | { type: "loading" }
    | { type: "success"; data: string }
    | { type: "error"; message: string };

// switch 不会强制穷举检查
function render(state: UiState) {
    switch (state.type) {
        case "loading": showLoading(); break;
        case "success": showData(state.data); break;
        case "error": showError(state.message); break;
        // 忘了某个 case？TS 不会报错
    }
}
```

Kotlin 的 sealed class 比 TS 的可辨识联合更强：编译器**强制**你处理所有分支。

### 实际应用：网络请求状态

```kotlin
sealed class Result<out T> {
    data class Success<T>(val data: T) : Result<T>()
    data class Error(val exception: Throwable) : Result<Nothing>()
    object Loading : Result<Nothing>()
}

// 使用
fun fetchUser(): Result<User> {
    return try {
        val user = api.getUser()
        Result.Success(user)
    } catch (e: Exception) {
        Result.Error(e)
    }
}

// UI 层处理
when (val result = viewModel.userState.value) {
    is Result.Loading -> showLoading()
    is Result.Success -> showUser(result.data)
    is Result.Error -> showError(result.exception.message ?: "未知错误")
}
```

### Sealed Class vs Enum

| 特性 | Sealed Class | Enum |
|------|-------------|------|
| 子类数量 | 有限 | 有限 |
| 每个子类可以有不同字段 | ✅ | ❌（所有值共享相同属性） |
| 子类可以是不同类型 | ✅（object / data class） | ❌（都是枚举常量） |
| 可以保存不同类型的数据 | ✅ | ❌ |
| when 穷举检查 | ✅ | ✅ |

```kotlin
// Enum — 每个值结构相同
enum class Status { LOADING, SUCCESS, ERROR }

// Sealed Class — 每个值可以有不同的数据
sealed class UiState {
    object Loading : UiState()                         // 无数据
    data class Success(val items: List<Item>) : UiState()  // 列表数据
    data class Error(val code: Int, val msg: String) : UiState()  // 错误详情
}
```

## 二、委托（Delegation）

### 2.1 by lazy — 惰性初始化

```kotlin
// 第一次访问时才初始化，之后缓存结果
val database: Database by lazy {
    println("初始化数据库连接...")  // 只打印一次
    Database.connect()
}

// 第一次访问 database 时才执行初始化
println("准备阶段")          // 准备阶段
database.query("SELECT *")   // 初始化数据库连接...（只执行一次）
database.query("SELECT 1")   // 不再初始化，直接使用缓存
```

**线程安全**：`lazy` 默认是线程安全的（`LazyThreadSafetyMode.SYNCHRONIZED`）。

```kotlin
// 如果确认只在单线程使用，可以关闭锁以提升性能
val cache by lazy(LazyThreadSafetyMode.NONE) {
    mutableMapOf<String, Any>()
}
```

**前端类比**：
```javascript
// JS 中类似的做法
let _database;
function getDatabase() {
    if (!_database) _database = Database.connect();
    return _database;
}
// Kotlin 的 by lazy 更简洁安全
```

### 2.2 by map — 用 Map 作为属性存储

```kotlin
class User(map: Map<String, Any?>) {
    val name: String by map           // 从 map["name"] 读取
    val age: Int by map               // 从 map["age"] 读取
}

val user = User(mapOf(
    "name" to "张三",
    "age" to 25
))
println(user.name)  // 张三
println(user.age)   // 25

// 可变版本
class MutableUser(map: MutableMap<String, Any?>) {
    var name: String by map
    var age: Int by map
}

val mutableMap = mutableMapOf("name" to "张三", "age" to 25)
val mUser = MutableUser(mutableMap)
mUser.age = 26              // 修改 map 中的值
println(mutableMap["age"])  // 26
```

### 2.3 自定义属性委托（Delegate 接口）

```kotlin
import kotlin.properties.ReadWriteProperty
import kotlin.reflect.KProperty

// 委托类必须实现 getValue 和 setValue
class Observable<T>(initialValue: T) : ReadWriteProperty<Any?, T> {
    private var value = initialValue

    override fun getValue(thisRef: Any?, property: KProperty<*>): T {
        println("${property.name} 被读取: $value")
        return value
    }

    override fun setValue(thisRef: Any?, property: KProperty<*>, value: T) {
        println("${property.name} 从 ${this.value} 变为 $value")
        this.value = value
    }
}

// 使用
class Config {
    var host: String by Observable("localhost")
    var port: Int by Observable(8080)
}

val config = Config()
config.host           // host 被读取: localhost
config.port = 3000    // port 从 8080 变为 3000
config.host = "example.com"  // host 从 localhost 变为 example.com
```

### 2.4 委托的实际应用

**Android ViewModel 中的委托**：

```kotlin
class UserViewModel : ViewModel() {
    // 使用委托简化 StateFlow 创建
    var name by mutableStateOf("")       // Compose 中
    var isLoading by mutableStateOf(false)

    // by viewModels() 委托创建 ViewModel
    // val viewModel: UserViewModel by viewModels()
}
```

**SharedPreferences 委托**：

```kotlin
class PreferenceDelegate<T>(
    private val prefs: SharedPreferences,
    private val key: String,
    private val defaultValue: T
) : ReadWriteProperty<Any?, T> {

    override fun getValue(thisRef: Any?, property: KProperty<*>): T {
        @Suppress("UNCHECKED_CAST")
        return when (defaultValue) {
            is String -> prefs.getString(key, defaultValue) as T
            is Int -> prefs.getInt(key, defaultValue) as T
            is Boolean -> prefs.getBoolean(key, defaultValue) as T
            is Float -> prefs.getFloat(key, defaultValue) as T
            is Long -> prefs.getLong(key, defaultValue) as T
            else -> throw IllegalArgumentException("不支持的类型")
        }
    }

    override fun setValue(thisRef: Any?, property: KProperty<*>, value: T) {
        prefs.edit().apply {
            when (value) {
                is String -> putString(key, value)
                is Int -> putInt(key, value)
                is Boolean -> putBoolean(key, value)
                is Float -> putFloat(key, value)
                is Long -> putLong(key, value)
                else -> throw IllegalArgumentException("不支持的类型")
            }
        }.apply()
    }
}

// 使用
class AppSettings(prefs: SharedPreferences) {
    var username: String by PreferenceDelegate(prefs, "username", "")
    var isFirstLaunch: Boolean by PreferenceDelegate(prefs, "isFirstLaunch", true)
    var launchCount: Int by PreferenceDelegate(prefs, "launchCount", 0)
}
```

### 第 3 题

```kotlin
import kotlin.properties.ReadWriteProperty
import kotlin.reflect.KProperty
import java.util.Timer
import java.util.TimerTask

class Debounce<T>(private val delay: Long, initialValue: T) : ReadWriteProperty<Any?, T> {
    private var value = initialValue
    private var timer: Timer? = null

    override fun getValue(thisRef: Any?, property: KProperty<*>): T = value

    override fun setValue(thisRef: Any?, property: KProperty<*>, value: T) {
        timer?.cancel()
        timer = Timer().apply {
            schedule(object : TimerTask() {
                override fun run() {
                    this@Debounce.value = value
                    println("${property.name} 延迟设置生效: $value")
                }
            }, delay)
        }
    }
}

// 使用
class SearchBar {
    var query: String by Debounce(300, "")
}

val searchBar = SearchBar()
searchBar.query = "K"      // 300ms 内被覆盖
searchBar.query = "Ko"     // 300ms 内被覆盖
searchBar.query = "Kot"    // 300ms 内被覆盖
searchBar.query = "Kotlin" // 300ms 后生效
```

### 第 4 题

```kotlin
sealed class Expr {
    data class Number(val value: Double) : Expr()
    data class Add(val left: Expr, val right: Expr) : Expr()
    data class Subtract(val left: Expr, val right: Expr) : Expr()
    data class Multiply(val left: Expr, val right: Expr) : Expr()
}

fun evaluate(expr: Expr): Double = when (expr) {
    is Expr.Number -> expr.value
    is Expr.Add -> evaluate(expr.left) + evaluate(expr.right)
    is Expr.Subtract -> evaluate(expr.left) - evaluate(expr.right)
    is Expr.Multiply -> evaluate(expr.left) * evaluate(expr.right)
}

// 使用：(3 + 4) * 5 = 35
val expression = Expr.Multiply(
    Expr.Add(Expr.Number(3.0), Expr.Number(4.0)),
    Expr.Number(5.0)
)
println(evaluate(expression))  // 35.0
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| Sealed Class | 限制继承层级；`when` 强制穷举所有分支；每个子类可有不同字段 |
| Sealed vs Enum | Sealed 子类可有不同结构/数据；Enum 所有值共享相同属性 |
| by lazy | 惰性初始化，首次访问时执行，之后缓存；默认线程安全 |
| by map | 用 Map 作为属性存储后端，动态读写 |
| 自定义委托 | 实现 `ReadWriteProperty` 的 `getValue`/`setValue` |
| 实际应用 | 网络请求状态管理、SharedPreferences 委托、ViewModel 状态 |
