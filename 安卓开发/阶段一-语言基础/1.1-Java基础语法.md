# 1.1 Java 基础语法

> 从零理解 Java 的变量、数据类型、运算符和流程控制。

---

## 一、变量

Java 是**强类型、静态类型**语言——每个变量必须声明类型，且类型在编译期确定，运行时不能改变。

```java
int age = 25;           // 整数
double price = 9.99;    // 浮点数
boolean active = true;  // 布尔值
char grade = 'A';       // 字符（单引号）
String name = "张三";   // 字符串（双引号，引用类型）
```

### 前端类比

| Java | JavaScript | 差异 |
|------|-----------|------|
| `int age = 25;` | `let age = 25;` | Java 必须写类型 |
| `final int MAX = 100;` | `const MAX = 100;` | `final` ≈ `const` |
| `String s = "hi";` | `let s = "hi";` | Java 中 String 是对象，不可变 |

## 二、数据类型

### 基本类型（Primitive）

| 类型 | 大小 | 范围 | 示例 |
|------|------|------|------|
| `byte` | 1 字节 | -128 ~ 127 | `byte b = 100;` |
| `short` | 2 字节 | -32768 ~ 32767 | `short s = 30000;` |
| `int` | 4 字节 | ±21 亿 | `int i = 100000;` |
| `long` | 8 字节 | 很大 | `long l = 9999999999L;` |
| `float` | 4 字节 | 6-7 位精度 | `float f = 3.14f;` |
| `double` | 8 字节 | 15 位精度 | `double d = 3.14;` |
| `boolean` | 1 位 | true/false | `boolean b = true;` |
| `char` | 2 字节 | Unicode | `char c = '中';` |

**要点**：
- 整数默认 `int`，浮点默认 `double`
- `long` 值要加 `L` 后缀，`float` 值要加 `f` 后缀
- `char` 用单引号，`String` 用双引号（String 不是基本类型）

### 引用类型

```java
String name = "张三";              // 字符串
int[] numbers = {1, 2, 3};        // 数组
List<String> list = new ArrayList<>();  // 集合
User user = new User();            // 自定义对象
```

### 类型转换

```java
// 自动转换（小 → 大）
int i = 100;
double d = i;        // int → double，自动

// 强制转换（大 → 小，可能丢失精度）
double pi = 3.14159;
int rounded = (int) pi;  // 结果为 3，小数部分截断

// 字符串与数字互转
String s = String.valueOf(123);     // 数字 → 字符串
int n = Integer.parseInt("456");    // 字符串 → 数字
```

## 三、运算符

### 算术运算符

```java
int a = 10, b = 3;
a + b;   // 13  加
a - b;   // 7   减
a * b;   // 30  乘
a / b;   // 3   整数除法（截断，不是 3.333）
a % b;   // 1   取模（余数）
```

> **注意**：`10 / 3` 在 Java 中结果是 `3`（整数除法），不是 `3.333`。要想得到小数，至少一方要是浮点：`10.0 / 3`。

### 比较运算符

```java
a == b;   // 等于
a != b;   // 不等于
a > b;    // 大于
a < b;    // 小于
a >= b;   // 大于等于
a <= b;   // 小于等于
```

### 字符串比较（重点）

```java
String s1 = "hello";
String s2 = new String("hello");

s1 == s2;         // false！比较的是引用（内存地址）
s1.equals(s2);    // true  比较的是内容
```

> **前端开发者常踩的坑**：Java 的 `==` 对对象比较的是引用，不是值。字符串比较**必须用 `.equals()`**。

### 逻辑运算符

```java
boolean a = true, b = false;
a && b;   // 逻辑与（短路与）  类似 JS &&
a || b;   // 逻辑或（短路或）  类似 JS ||
!a;       // 逻辑非            类似 JS !
```

### 三元运算符

```java
String result = score >= 60 ? "及格" : "不及格";
// 完全等同于 JS 的三元表达式
```

## 四、流程控制

### if-else

```java
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### switch

```java
switch (day) {
    case "Monday":
        System.out.println("周一");
        break;                    // 必须 break，否则会穿透
    case "Friday":
        System.out.println("周五");
        break;
    default:
        System.out.println("其他");
        break;
}
```

Java 的 switch 支持：`byte`, `short`, `int`, `char`, `String`（Java 7+）, `enum`。

> **与 JS 的区别**：Java 的 switch 不支持 `===` 以外的比较，但支持 String 和 enum。

### for 循环

```java
// 经典 for
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}

// 增强 for（遍历集合/数组，类似 JS for...of）
int[] nums = {1, 2, 3, 4, 5};
for (int n : nums) {
    System.out.println(n);
}
```

### while / do-while

```java
// while — 先判断再执行
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

// do-while — 先执行再判断（至少执行一次）
int j = 0;
do {
    System.out.println(j);
    j++;
} while (j < 5);
```

### break 与 continue

```java
// break — 跳出整个循环
for (int i = 0; i < 10; i++) {
    if (i == 5) break;     // 循环在 i=5 时终止
}

// continue — 跳过本次迭代
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数
    System.out.println(i);     // 只打印奇数
}
```

## 五、数组

```java
// 声明与初始化
int[] arr1 = new int[5];           // 长度为 5，默认值全为 0
int[] arr2 = {1, 2, 3, 4, 5};     // 直接初始化
String[] names = {"张三", "李四"};

// 访问与修改
arr2[0];          // 1（索引从 0 开始）
arr2[0] = 10;     // 修改第一个元素
arr2.length;      // 5（数组长度）

// 遍历
for (int n : arr2) {
    System.out.println(n);
}
```

> **与 JS 的区别**：Java 数组长度固定，不能动态增删。需要动态集合请用 `ArrayList`。

## 练习

1. 声明一个 `String[]` 数组存储 5 个城市名，用 for 循环打印每个城市
2. 写一个方法，接收一个 `int` 分数，返回等级字符串（A/B/C/D）
3. 用 `while` 循环计算 1 到 100 的整数和

---

## 参考答案

### 第 1 题

```java
String[] cities = {"北京", "上海", "广州", "深圳", "杭州"};
for (int i = 0; i < cities.length; i++) {
    System.out.println(cities[i]);
}
```

### 第 2 题

```java
public static String getGrade(int score) {
    if (score >= 90) {
        return "A";
    } else if (score >= 80) {
        return "B";
    } else if (score >= 60) {
        return "C";
    } else {
        return "D";
    }
}
```

### 第 3 题

```java
int sum = 0;
int i = 1;
while (i <= 100) {
    sum += i;
    i++;
}
System.out.println("1到100的和: " + sum);  // 5050
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| 变量声明 | Java 是强类型静态语言，必须声明类型；`final` ≈ JS `const` |
| 基本数据类型 | 8 种基本类型：`byte`/`short`/`int`/`long`/`float`/`double`/`boolean`/`char` |
| 类型转换 | 小→大自动转换，大→小需强制转换；`Integer.parseInt()` 字符串转数字 |
| 运算符 | 算术/比较/逻辑/三元运算符；整数除法截断；字符串比较必须用 `.equals()` |
| 流程控制 | `if-else`/`switch`/`for`/`while`/`do-while`/`break`/`continue` |
| 数组 | 长度固定，索引从 0 开始；动态集合用 `ArrayList` |
| 前端差异 | `==` 比较引用不是值；`10/3=3` 不是 3.333；数组不能动态增删 |
