# 1.5 Java 反射基础

> 理解反射的概念和基本用法——在运行时检查和操作类、方法、字段。

---

## 一、什么是反射

反射（Reflection）允许程序在**运行时**获取类的信息（字段、方法、构造函数），并动态调用。

普通方式：编译时就知道类名和方法名 → 直接调用
反射方式：运行时才知道类名 → 动态获取和调用

### 前端类比

```javascript
// JS 天然支持"反射"
const methodName = "sayHello";
obj[methodName]();           // 动态调用方法
obj["name"];                 // 动态访问属性
Object.keys(obj);            // 获取所有属性名

// Java 需要通过反射 API 实现类似功能
```

Java 是静态类型语言，不像 JS 那样天然支持动态访问，所以需要反射机制。

## 二、获取 Class 对象

三种方式：

```java
// 方式 1：类名.class（编译时已知类型）
Class<?> clazz1 = User.class;

// 方式 2：对象.getClass()（运行时从实例获取）
User user = new User();
Class<?> clazz2 = user.getClass();

// 方式 3：Class.forName()（通过全类名，最灵活）
Class<?> clazz3 = Class.forName("com.example.User");
```

---

## 三、获取类信息

```java
Class<?> clazz = User.class;

// 类名
clazz.getName();          // "com.example.User"（全限定名）
clazz.getSimpleName();    // "User"（简单类名）

// 父类
Class<?> superClass = clazz.getSuperclass();

// 实现的接口
Class<?>[] interfaces = clazz.getInterfaces();

// 修饰符（public, abstract 等）
int modifiers = clazz.getModifiers();
Modifier.isPublic(modifiers);
Modifier.isAbstract(modifiers);
```

## 四、获取字段

```java
Class<?> clazz = User.class;

// 获取所有 public 字段（含继承的）
Field[] publicFields = clazz.getFields();

// 获取本类声明的所有字段（含 private，不含继承的）
Field[] allFields = clazz.getDeclaredFields();

// 获取指定字段
Field nameField = clazz.getDeclaredField("name");

// 访问 private 字段需要取消访问检查
nameField.setAccessible(true);
```

---

## 五、获取方法

```java
Class<?> clazz = User.class;

// 获取所有 public 方法（含继承的）
Method[] publicMethods = clazz.getMethods();

// 获取本类声明的所有方法（含 private）
Method[] allMethods = clazz.getDeclaredMethods();

// 获取指定方法（方法名 + 参数类型）
Method setNameMethod = clazz.getDeclaredMethod("setName", String.class);
Method getNameMethod = clazz.getDeclaredMethod("getName");
```

## 六、通过反射创建对象

```java
Class<?> clazz = User.class;

// 方式 1：调用无参构造
Object obj1 = clazz.newInstance();  // 已废弃，不推荐

// 方式 2：通过 Constructor（推荐）
Constructor<?> constructor = clazz.getDeclaredConstructor(String.class, int.class);
Object obj2 = constructor.newInstance("张三", 25);
```

---

## 七、通过反射调用方法

```java
Class<?> clazz = User.class;
Object instance = clazz.getDeclaredConstructor().newInstance();

// 获取方法
Method setNameMethod = clazz.getDeclaredMethod("setName", String.class);

// 调用方法：invoke(对象实例, 参数...)
setNameMethod.invoke(instance, "张三");

// 获取并调用 getter
Method getNameMethod = clazz.getDeclaredMethod("getName");
String name = (String) getNameMethod.invoke(instance);  // "张三"
```

---

## 八、通过反射访问字段

```java
Class<?> clazz = User.class;
Object instance = clazz.getDeclaredConstructor().newInstance();

// 获取字段
Field nameField = clazz.getDeclaredField("name");
nameField.setAccessible(true);  // private 字段需要这行

// 读取字段值
nameField.set(instance, "李四");                 // 设置值
String value = (String) nameField.get(instance);  // 读取值 → "李四"
```

## 九、实际应用场景

### 1. Android 中的反射

```java
// 通过反射获取系统隐藏 API
try {
    Method method = Activity.class.getDeclaredMethod("getWindow");
    method.setAccessible(true);
    Object window = method.invoke(activity);
} catch (Exception e) {
    e.printStackTrace();
}
```

### 2. Retrofit / Gson 等库的原理

这些库通过反射获取类信息和注解，在运行时生成实现：

```java
// Gson 反序列化 JSON → 对象
String json = "{\"name\":\"张三\",\"age\":25}";
User user = new Gson().fromJson(json, User.class);
// Gson 内部用反射获取 User 的字段，把 JSON 值填进去
```

### 3. 注解处理器

```java
// 获取类上的注解
@Deprecated
public class OldClass {}

Class<?> clazz = OldClass.class;
if (clazz.isAnnotationPresent(Deprecated.class)) {
    Deprecated annotation = clazz.getAnnotation(Deprecated.class);
    System.out.println("这个类已过时");
}
```

## 十、反射的注意事项

| 问题 | 说明 |
|------|------|
| 性能开销 | 反射比直接调用慢，避免在热路径频繁使用 |
| 安全风险 | `setAccessible(true)` 可以绕过访问控制 |
| 破坏封装 | 直接操作 private 字段破坏了面向对象的封装性 |
| 代码可读性 | 反射代码不如直接调用直观 |
| 编译期检查缺失 | 反射调用在编译期不检查类型，错误只能在运行时发现 |
