# 1.3 Java 抽象类与接口

> 理解抽象类和接口的区别与使用场景，掌握 Java 中定义契约的两种方式。

---

## 一、抽象类（Abstract Class）

抽象类是**不能被实例化**的类，用于定义公共模板，子类必须实现其抽象方法。

```java
// 定义抽象类
public abstract class Shape {
    protected String color;

    public Shape(String color) {
        this.color = color;
    }

    // 抽象方法 — 没有方法体，子类必须实现
    public abstract double getArea();

    // 具体方法 — 子类可以直接继承使用
    public String describe() {
        return color + "的图形，面积=" + getArea();
    }
}
```

```java
// 子类实现抽象方法
public class Circle extends Shape {
    private double radius;

    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
}

// 使用
Shape shape = new Circle("红色", 5.0);
System.out.println(shape.describe());  // 红色的图形，面积=78.539...
```

### 抽象类的特点

| 特性 | 说明 |
|------|------|
| 不能实例化 | `new Shape()` 编译报错 |
| 可以有构造函数 | 供子类调用 `super()` |
| 可以有抽象方法 | 子类必须实现 |
| 可以有具体方法 | 子类可以直接继承 |
| 可以有字段 | 和普通类一样 |

### 前端类比

```typescript
// TypeScript 中类似的概念
abstract class Shape {
    protected color: string;
    constructor(color: string) { this.color = color; }
    abstract getArea(): number;   // 抽象方法
    describe(): string {          // 具体方法
        return `${this.color}的图形，面积=${this.getArea()}`;
    }
}
```

## 二、接口（Interface）

接口是纯粹的**行为契约**，定义一组方法签名，类通过 `implements` 来实现。

```java
// 定义接口
public interface Drawable {
    void draw();                              // 抽象方法（默认 public abstract）
    void resize(double factor);

    // Java 8+ 默认方法（有方法体）
    default void drawWithBorder() {
        draw();
        System.out.println("绘制边框");
    }

    // Java 8+ 静态方法
    static void log(String message) {
        System.out.println("[Drawable] " + message);
    }
}
```

```java
// 实现接口
public class Canvas implements Drawable {
    @Override
    public void draw() {
        System.out.println("在画布上绘制");
    }

    @Override
    public void resize(double factor) {
        System.out.println("缩放比例: " + factor);
    }
}

Canvas canvas = new Canvas();
canvas.draw();            // 在画布上绘制
canvas.drawWithBorder();  // 在画布上绘制 + 绘制边框（默认方法）
Drawable.log("测试");     // [Drawable] 测试（静态方法）
```

### 接口的特点

| 特性 | 说明 |
|------|------|
| 不能实例化 | `new Drawable()` 编译报错 |
| 方法默认 `public abstract` | 接口中的方法默认公开且抽象 |
| 没有构造函数 | 接口不参与实例化 |
| 可以有 `default` 方法 | Java 8+ 支持默认实现 |
| 可以有 `static` 方法 | Java 8+ 支持 |
| 可以有常量 | `public static final` |

## 三、一个类实现多个接口

Java 虽然只能继承一个类，但**可以实现多个接口**：

```java
public interface Flyable {
    void fly();
}

public interface Swimmable {
    void swim();
}

// 同时实现两个接口
public class Duck implements Flyable, Swimmable {
    @Override
    public void fly() {
        System.out.println("鸭子在飞");
    }

    @Override
    public void swim() {
        System.out.println("鸭子在游泳");
    }
}
```

## 四、抽象类 vs 接口

| 对比项 | 抽象类 | 接口 |
|--------|--------|------|
| 关键字 | `abstract class` | `interface` |
| 继承/实现 | `extends`（单继承） | `implements`（多实现） |
| 构造函数 | ✅ 有 | ❌ 没有 |
| 字段 | 任意类型 | 只能是 `public static final` 常量 |
| 方法 | 抽象 + 具体都行 | 默认抽象，可有 `default` 方法 |
| 设计目的 | "是什么"（is-a 关系） | "能做什么"（can-do 能力） |
| 前端类比 | TS 的 `abstract class` | TS 的 `interface` |

### 选择原则

- 用**抽象类**：多个子类有共同代码要复用（如 `BaseActivity`）
- 用**接口**：定义能力/行为契约（如 `OnClickListener`、`Comparable`）

---

## 五、接口的默认方法冲突

当一个类实现了两个接口，两个接口有同名的 default 方法时：

```java
public interface A {
    default void hello() { System.out.println("A"); }
}

public interface B {
    default void hello() { System.out.println("B"); }
}

// 必须显式指定用哪个
public class C implements A, B {
    @Override
    public void hello() {
        A.super.hello();  // 选择 A 的默认实现
    }
}
```

## 六、实际应用示例

### Android 中的典型用法

```java
// 接口 — 定义点击回调（类似 JS 的回调函数）
public interface OnItemClickListener {
    void onItemClick(int position);
    void onItemLongClick(int position);
}

// 抽象类 — Activity 基类（模板方法模式）
public abstract class BaseActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(getLayoutId());   // 子类提供布局
        initViews();
        loadData();
    }

    protected abstract int getLayoutId();  // 子类必须实现
    protected void initViews() {}          // 子类可选重写
    protected void loadData() {}           // 子类可选重写
}
```

## 参考答案

### 第 1 题

```java
public interface Sortable {
    int compareTo(Sortable other);
}

public class Student implements Sortable {
    private String name;
    private int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    public String getName() { return name; }
    public int getScore() { return score; }

    @Override
    public int compareTo(Sortable other) {
        if (other instanceof Student) {
            return Integer.compare(this.score, ((Student) other).score);
        }
        return 0;
    }
}

// 使用
List<Student> students = Arrays.asList(
    new Student("张三", 85),
    new Student("李四", 92),
    new Student("王五", 78)
);
Collections.sort(students, (a, b) -> a.compareTo(b));
```

### 第 2 题

```java
public abstract class Vehicle {
    protected String brand;

    public Vehicle(String brand) {
        this.brand = brand;
    }

    public abstract void start();

    public void displayBrand() {
        System.out.println("品牌: " + brand);
    }
}

public class Car extends Vehicle {
    private int doors;

    public Car(String brand, int doors) {
        super(brand);
        this.doors = doors;
    }

    @Override
    public void start() {
        System.out.println(brand + " 汽车启动，引擎轰鸣！" + doors + "门");
    }
}

public class Bicycle extends Vehicle {
    public Bicycle(String brand) {
        super(brand);
    }

    @Override
    public void start() {
        System.out.println(brand + " 自行车启动，开始蹬踏板！");
    }
}
```

### 第 3 题

```java
public interface Clickable {
    void onClick();
    void onDoubleClick();
}

public interface Draggable {
    void onDragStart();
    void onDragEnd();
}

public class Button implements Clickable, Draggable {
    private String label;

    public Button(String label) {
        this.label = label;
    }

    @Override
    public void onClick() {
        System.out.println("[" + label + "] 被点击");
    }

    @Override
    public void onDoubleClick() {
        System.out.println("[" + label + "] 被双击");
    }

    @Override
    public void onDragStart() {
        System.out.println("[" + label + "] 开始拖拽");
    }

    @Override
    public void onDragEnd() {
        System.out.println("[" + label + "] 拖拽结束");
    }
}
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| 抽象类 | `abstract class`，不能实例化；可有抽象方法和具体方法；子类必须实现所有抽象方法 |
| 接口 | `interface`，纯行为契约；Java 8+ 支持 `default` 和 `static` 方法 |
| 多实现 | 一个类可以 `implements` 多个接口，弥补单继承限制 |
| 抽象类 vs 接口 | 抽象类 = "是什么"（有状态/构造函数）；接口 = "能做什么"（无状态/纯行为） |
| 默认方法冲突 | 两个接口有同名 default 方法时，实现类必须显式指定用哪个 |
| 选择原则 | 有共同代码复用 → 抽象类；定义能力契约 → 接口 |
