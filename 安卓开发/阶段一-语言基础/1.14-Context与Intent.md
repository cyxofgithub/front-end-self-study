# 1.14 Context 与 Intent

> 理解 Context 的概念和使用场景，掌握 Intent 页面跳转和参数传递。

---

## 一、Context

### 什么是 Context？

Context 是 Android 的"上帝对象"，提供对系统资源和类的访问。你可以把它理解为**应用环境的上下文**。

### Context 的类型

| 类型 | 获取方式 | 生命周期 | 用途 |
|------|----------|----------|------|
| Activity Context | `this`（Activity 内部） | 跟随 Activity | UI 相关操作 |
| Application Context | `applicationContext` | 跟随整个应用 | 全局单例、长生命周期对象 |

### 前端类比

```
Context                     前端类比
─────────                   ──────────
Activity Context       ≈    组件实例 this
Application Context    ≈    全局 App 实例 / window

context.getString()    ≈    i18n 翻译函数
context.startActivity  ≈    router.push()
context.getSystemService ≈  注入系统服务（类似依赖注入）
```

### 常见使用场景

```kotlin
// 1. 加载资源
val appName = context.getString(R.string.app_name)
val color = ContextCompat.getColor(context, R.color.primary)
val drawable = ContextCompat.getDrawable(context, R.drawable.icon)

// 2. 启动 Activity
val intent = Intent(context, DetailActivity::class.java)
context.startActivity(intent)

// 3. 获取系统服务
val connectivityManager = context.getSystemService(Context.CONNECTIVITY_SERVICE) as ConnectivityManager
val windowManager = context.getSystemService(Context.WINDOW_SERVICE) as WindowManager
val inflater = context.getSystemService(Context.LAYOUT_INFLATER_SERVICE) as LayoutInflater

// 4. 弹出 Toast
Toast.makeText(context, "操作成功", Toast.LENGTH_SHORT).show()

// 5. 访问文件
val sharedPrefs = context.getSharedPreferences("settings", Context.MODE_PRIVATE)
val file = context.getFileStreamPath("data.json")

// 6. 布局填充
val view = LayoutInflater.from(context).inflate(R.layout.item, parent, false)
```

### 什么时候用哪个 Context？

| 场景 | 推荐 | 原因 |
|------|------|------|
| Toast | Application | Toast 生命周期可能超出 Activity |
| Dialog | Activity | Dialog 需要 Activity 的 Window |
| 启动 Activity | Activity | 需要任务栈管理 |
| 单例/工具类 | Application | 避免持有 Activity 导致内存泄漏 |
| Adapter | Activity | 可能需要访问 Activity 的方法 |
| Service | Application | Service 生命周期可能较长 |

> **关键原则**：生命周期长的对象用 Application Context，UI 相关的用 Activity Context。用 Activity Context 持有长生命周期对象会导致**内存泄漏**。

## 二、Intent

### 什么是 Intent？

Intent 是 Android 中的"意图"对象，用于请求执行某个操作（如跳转页面、启动服务、发送广播）。

### 显式 Intent — 跳转到指定页面

```kotlin
// 基本跳转
val intent = Intent(this, DetailActivity::class.java)
startActivity(intent)

// 传递参数
val intent = Intent(this, DetailActivity::class.java).apply {
    putExtra("id", 123)
    putExtra("name", "张三")
    putExtra("isVip", true)
}
startActivity(intent)

// 接收参数（在 DetailActivity 中）
val id = intent.getIntExtra("id", 0)           // 123
val name = intent.getStringExtra("name")       // "张三"
val isVip = intent.getBooleanExtra("isVip", false)  // true
```

> **前端类比**：`Intent + putExtra` ≈ `router.push({ path: '/detail', query: { id: 123, name: '张三' } })`

### 隐式 Intent — 调用系统功能

```kotlin
// 打开网页
val webIntent = Intent(Intent.ACTION_VIEW, Uri.parse("https://www.example.com"))
startActivity(webIntent)

// 拨打电话
val callIntent = Intent(Intent.ACTION_DIAL, Uri.parse("tel:10086"))
startActivity(callIntent)

// 发送短信
val smsIntent = Intent(Intent.ACTION_SENDTO, Uri.parse("smsto:10086"))
smsIntent.putExtra("sms_body", "你好")
startActivity(smsIntent)

// 打开地图
val mapIntent = Intent(Intent.ACTION_VIEW, Uri.parse("geo:39.9042,116.4074"))
startActivity(mapIntent)

// 分享文本
val shareIntent = Intent(Intent.ACTION_SEND).apply {
    type = "text/plain"
    putExtra(Intent.EXTRA_TEXT, "分享的内容")
}
startActivity(Intent.createChooser(shareIntent, "分享到"))

// 拍照
val cameraIntent = Intent(MediaStore.ACTION_IMAGE_CAPTURE)
startActivityForResult(cameraIntent, REQUEST_CAMERA)
```

> **前端类比**：隐式 Intent ≈ `<a href="tel:10086">` 或 `navigator.share()`，调用系统已有的应用来处理。

### 带回调的跳转

```kotlin
// 发起跳转
val intent = Intent(this, EditActivity::class.java)
startActivityForResult(intent, REQUEST_CODE_EDIT)

// 接收返回结果
override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
    super.onActivityResult(requestCode, resultCode, data)
    if (requestCode == REQUEST_CODE_EDIT && resultCode == Activity.RESULT_OK) {
        val result = data?.getStringExtra("result")
        println("编辑结果: $result")
    }
}

// 在 EditActivity 中设置返回结果
val resultIntent = Intent().apply {
    putExtra("result", "编辑完成")
}
setResult(Activity.RESULT_OK, resultIntent)
finish()  // 关闭当前页面
```

### 新版 Activity Result API（推荐）

```kotlin
// 注册回调（在 onCreate 之前）
private val editLauncher = registerForActivityResult(
    ActivityResultContracts.StartActivityForResult()
) { result ->
    if (result.resultCode == Activity.RESULT_OK) {
        val data = result.data?.getStringExtra("result")
        println("编辑结果: $data")
    }
}

// 发起跳转
val intent = Intent(this, EditActivity::class.java)
editLauncher.launch(intent)
```

### 传递复杂对象

```kotlin
// 方法 1：Serializable（简单但慢）
data class User(val name: String, val age: Int) : Serializable

val intent = Intent(this, DetailActivity::class.java).apply {
    putExtra("user", User("张三", 25))
}

// 接收
val user = intent.getSerializableExtra("user") as? User

// 方法 2：Parcelable（推荐，快但需要样板代码）
@Parcelize
data class User(val name: String, val age: Int) : Parcelable

val intent = Intent(this, DetailActivity::class.java).apply {
    putExtra("user", User("张三", 25))
}

// 接收
val user = intent.getParcelableExtra<User>("user")

// 方法 3：传递 ID，目标页面自己查数据（最佳实践）
val intent = Intent(this, DetailActivity::class.java).apply {
    putExtra("userId", "123")
}
// DetailActivity 中通过网络/数据库获取完整用户数据
```

## 三、Intent Flags

Flags 用来控制 Activity 的启动行为：

```kotlin
// 常用 Flags
intent.flags = Intent.FLAG_ACTIVITY_NEW_TASK      // 在新任务栈中启动
intent.flags = Intent.FLAG_ACTIVITY_CLEAR_TOP     // 清除目标上面的 Activity
intent.flags = Intent.FLAG_ACTIVITY_SINGLE_TOP    // 如果已在栈顶则复用

// 组合使用：清空栈并作为新任务
intent.flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TASK

// 典型场景：登录成功后跳主页，清掉登录页
val intent = Intent(this, HomeActivity::class.java).apply {
    flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TASK
}
startActivity(intent)
```

> **前端类比**：Flags ≈ 路由的导航策略（如 `router.replace()` 清掉历史记录、`router.push()` 保留）。
