# 1.13 Fragment 管理

> 掌握 Fragment 的添加、替换、隐藏、显示和返回栈操作。

---

## 一、FragmentManager

`FragmentManager` 负责管理 Activity 中的 Fragment。

```kotlin
// 获取 FragmentManager
val fragmentManager = supportFragmentManager

// 开始事务
val transaction = fragmentManager.beginTransaction()
```

---

## 二、Fragment 操作

### 添加（add）

```kotlin
supportFragmentManager.beginTransaction()
    .add(R.id.fragment_container, HomeFragment(), "home")
    .commit()
```

- `R.id.fragment_container` — 容器 View 的 ID
- `HomeFragment()` — 要添加的 Fragment 实例
- `"home"` — 可选的 tag，后续可以通过 tag 找到这个 Fragment

### 替换（replace）

```kotlin
supportFragmentManager.beginTransaction()
    .replace(R.id.fragment_container, DetailFragment())
    .commit()
```

- 替换容器中的所有 Fragment（会销毁之前的 Fragment）

### 隐藏（hide）与显示（show）

```kotlin
val transaction = supportFragmentManager.beginTransaction()

// 隐藏 — Fragment 不销毁，只是不可见
transaction.hide(homeFragment)

// 显示 — 重新显示隐藏的 Fragment
transaction.show(homeFragment)

transaction.commit()
```

### 移除（remove）

```kotlin
supportFragmentManager.beginTransaction()
    .remove(detailFragment)
    .commit()
```

## 三、返回栈（BackStack）

返回栈类似浏览器的历史栈，允许用户按返回键回退到上一个 Fragment。

```kotlin
// 添加到返回栈
supportFragmentManager.beginTransaction()
    .replace(R.id.container, DetailFragment())
    .addToBackStack("detail")  // 按 back 可回退
    .commit()

// 不添加到返回栈
supportFragmentManager.beginTransaction()
    .replace(R.id.container, HomeFragment())
    // 不调用 addToBackStack，按 back 直接退出 Activity
    .commit()
```

### 前端类比

```
Fragment 返回栈         浏览器 History API
─────────────────      ─────────────────
addToBackStack()   ≈   history.pushState()
按返回键            ≈   history.back()
popBackStack()     ≈   history.back()
```

## 四、常见模式

### 模式一：Tab 切换（add + hide/show）

适合底部导航栏场景，Fragment 不销毁，切换时隐藏/显示：

```kotlin
class MainActivity : AppCompatActivity() {
    private var currentFragment: Fragment? = null
    private val homeFragment = HomeFragment()
    private val profileFragment = ProfileFragment()
    private val settingsFragment = SettingsFragment()

    private fun switchFragment(target: Fragment) {
        if (target == currentFragment) return

        val transaction = supportFragmentManager.beginTransaction()

        // 隐藏当前 Fragment
        currentFragment?.let { transaction.hide(it) }

        // 如果目标 Fragment 未添加过，则添加
        if (!target.isAdded) {
            transaction.add(R.id.container, target)
        } else {
            // 已添加过，直接显示
            transaction.show(target)
        }

        transaction.commit()
        currentFragment = target
    }

    // 底部导航点击事件
    fun onTabSelected(tab: Tab) {
        when (tab) {
            Tab.HOME -> switchFragment(homeFragment)
            Tab.PROFILE -> switchFragment(profileFragment)
            Tab.SETTINGS -> switchFragment(settingsFragment)
        }
    }
}
```

> **优点**：Fragment 不销毁，切换速度快，保持各 Fragment 的状态。

### 模式二：页面跳转（replace + backstack）

适合页面流式跳转（如列表 → 详情 → 编辑）：

```kotlin
// 列表 → 详情
fun openDetail(itemId: String) {
    val fragment = DetailFragment.newInstance(itemId)
    supportFragmentManager.beginTransaction()
        .replace(R.id.container, fragment)
        .addToBackStack(null)
        .commit()
}

// 详情 → 编辑
fun openEdit(itemId: String) {
    val fragment = EditFragment.newInstance(itemId)
    supportFragmentManager.beginTransaction()
        .replace(R.id.container, fragment)
        .addToBackStack(null)
        .commit()
}

// 用户按返回键 → 依次回退
```

### 模式三：ViewPager + Fragment

适合左右滑动切换（如 TabLayout + ViewPager）：

```kotlin
class ViewPagerAdapter(activity: FragmentActivity) : FragmentStateAdapter(activity) {

    override fun getItemCount() = 3

    override fun createFragment(position: Int): Fragment {
        return when (position) {
            0 -> HomeFragment()
            1 -> DiscoverFragment()
            2 -> ProfileFragment()
            else -> throw IllegalArgumentException()
        }
    }
}

// Activity 中设置
val adapter = ViewPagerAdapter(this)
viewPager.adapter = adapter

// 配合 TabLayout
TabLayoutMediator(tabLayout, viewPager) { tab, position ->
    tab.text = when (position) {
        0 -> "首页"
        1 -> "发现"
        2 -> "我的"
        else -> ""
    }
}.attach()
```

## 五、Fragment 间通信

### 通过 ViewModel（推荐）

```kotlin
// 共享 ViewModel
class SharedViewModel : ViewModel() {
    private val _selectedItem = MutableStateFlow<Item?>(null)
    val selectedItem: StateFlow<Item?> = _selectedItem

    fun select(item: Item) {
        _selectedItem.value = item
    }
}

// 列表 Fragment
class ListFragment : Fragment() {
    private val viewModel: SharedViewModel by activityViewModels()

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        recyclerView.adapter = ItemAdapter { item ->
            viewModel.select(item)  // 选中某个 item
        }
    }
}

// 详情 Fragment
class DetailFragment : Fragment() {
    private val viewModel: SharedViewModel by activityViewModels()

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        viewLifecycleOwner.lifecycleScope.launch {
            viewModel.selectedItem.collect { item ->
                item?.let { updateUI(it) }
            }
        }
    }
}
```

### 通过 Fragment Result API

```kotlin
// Fragment A — 发送结果
button.setOnClickListener {
    val result = "Hello from A"
    parentFragmentManager.setFragmentResult("requestKey", bundleOf("data" to result))
}

// Fragment B — 接收结果
parentFragmentManager.setFragmentResultListener("requestKey", viewLifecycleOwner) { _, bundle ->
    val data = bundle.getString("data")
    println(data)  // Hello from A
}
```

## 六、注意事项

1. **commit() vs commitNow()**
   - `commit()` — 异步，排队执行（推荐）
   - `commitNow()` — 同步，立即执行（注意不要在回调中嵌套使用）

2. **commitAllowingStateLoss()**
   - 允许在 `onSaveInstanceState` 之后提交（可能导致状态丢失）
   - 只在特殊场景使用

3. **Fragment 重建**
   - 系统可能销毁并重建 Fragment
   - 不要在构造函数中传参数，使用 `newInstance` 模式：

```kotlin
class DetailFragment : Fragment() {
    companion object {
        fun newInstance(itemId: String) = DetailFragment().apply {
            arguments = bundleOf("itemId" to itemId)
        }
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        val itemId = arguments?.getString("itemId") ?: return
        loadItem(itemId)
    }
}
```
