# 1.10 Kotlin 扩展函数与 Lambda

> 掌握扩展函数（给已有类添加方法）和高阶函数与 Lambda 表达式。

---

## 一、扩展函数

扩展函数让你**给已有的类添加方法**，不需要修改原始类，也不需要继承。

### 基本用法

```kotlin
// 给 String 添加一个方法
fun String.isEmail(): Boolean {
    return this.contains("@") && this.contains(".")
}

// 使用
"test@example.com".isEmail()  // true
"hello".isEmail()              // false
```

- `this` 指向接收者对象（即调用方法的那个 String）
- 可以访问接收者的 public 成员

### 给标准库类型添加扩展

```kotlin
// 给 Int 添加扩展
fun Int.isEven(): Boolean = this % 2 == 0
10.isEven()   // true
7.isEven()    // false

// 给 List 添加扩展
fun <T> List<T>.second(): T = this[1]
listOf(1, 2, 3).second()  // 2

// 给 View 添加扩展（Android 中非常常见）
fun View.visible() { visibility = View.VISIBLE }
fun View.gone() { visibility = View.GONE }
fun View.invisible() { visibility = View.INVISIBLE }

// 使用
textView.visible()
button.gone()
```

### 前端类比

```typescript
// TypeScript 中类似的做法（声明合并）
interface String {
    isEmail(): boolean;
}
String.prototype.isEmail = function() {
    return this.includes("@") && this.includes(".");
};

// Kotlin 的扩展函数更安全：静态解析、不修改原型链
```

### 扩展属性

```kotlin
val String.wordCount: Int
    get() = this.split(" ").size

"hello world kotlin".wordCount  // 3
```

### 注意事项

```kotlin
// 扩展函数是静态解析的——不依赖运行时类型
open class Animal
class Dog : Animal

fun Animal.sound() = "动物叫声"
fun Dog.sound() = "汪汪汪"

val animal: Animal = Dog()
animal.sound()  // "动物叫声"（不是"汪汪汪"！看声明类型，不看实际类型）

// 扩展函数不能访问 private/protected 成员
```

## 二、高阶函数

高阶函数是**以函数作为参数或返回值**的函数。

### 基本概念

```kotlin
// 函数类型：(参数类型) -> 返回类型
val sum: (Int, Int) -> Int = { a, b -> a + b }
val square: (Int) -> Int = { x -> x * x }

// 高阶函数 — 接受函数参数
fun operate(a: Int, b: Int, operation: (Int, Int) -> Int): Int {
    return operation(a, b)
}

operate(3, 4) { x, y -> x + y }  // 7
operate(3, 4) { x, y -> x * y }  // 12
```

### 前端类比

```javascript
// JS 的高阶函数
function operate(a, b, operation) {
    return operation(a, b);
}
operate(3, 4, (x, y) => x + y);  // 7

// Kotlin 写法几乎一模一样
```

## 三、Lambda 表达式

Lambda 是匿名函数的简洁写法。

### 基本语法

```kotlin
// 完整语法
{ a: Int, b: Int -> a + b }

// 类型推断可以省略参数类型
{ a, b -> a + b }

// 单参数可以用 it 代替
{ it * 2 }  // 等价于 { x -> x * 2 }
```

### 常见用法

```kotlin
// 集合操作
val numbers = listOf(1, 2, 3, 4, 5)

numbers.filter { it > 3 }           // [4, 5]
numbers.map { it * 2 }              // [2, 4, 6, 8, 10]
numbers.forEach { println(it) }
numbers.sortedBy { -it }            // [5, 4, 3, 2, 1]

// Lambda 作为最后一个参数可以提到括号外面
numbers.filter() { it > 3 }   // 等价于 numbers.filter({ it > 3 })
numbers.filter { it > 3 }     // 括号可以省略
```

### it — 隐式单参数

当 Lambda 只有一个参数时，可以用 `it` 代替：

```kotlin
// 以下两种写法等价
list.map { x -> x * 2 }
list.map { it * 2 }

// 多参数时不能用 it
list.mapIndexed { index, value -> "[$index]=$value" }
```

### Lambda 中解构

```kotlin
val pairs = listOf("a" to 1, "b" to 2, "c" to 3)

pairs.map { (key, value) -> "$key = $value" }
// ["a = 1", "b = 2", "c = 3"]
```

## 四、常用高阶函数

### let

```kotlin
// let — 对象不为 null 时执行操作
val name: String? = "张三"
name?.let {
    println("名字长度: ${it.length}")  // it = "张三"
}

// 常用于链式调用和空安全
val result = fetchUser()
    ?.let { formatUser(it) }
    ?.let { saveToCache(it) }
```

### apply

```kotlin
// apply — 配置对象并返回对象本身（this 指向对象）
val user = User().apply {
    name = "张三"
    age = 25
    email = "zhangsan@example.com"
}
// 返回 User 对象

// Android 中常用
val textView = TextView(context).apply {
    text = "Hello"
    textSize = 16f
    setTextColor(Color.BLACK)
}
```

### also

```kotlin
// also — 执行附加操作，返回对象本身（it 指向对象）
val numbers = mutableListOf(1, 2, 3).also {
    println("原始列表: $it")  // 附加操作
}
// numbers = [1, 2, 3]
```

### run

```kotlin
// run — 执行代码块，返回结果
val result = "Hello, World!".run {
    length to uppercase()
}
// result = (13, "HELLO, WORLD!")

// 对象的 run
val user = User("张三", 25)
val info = user.run {
    "$name, $age 岁"
}
```

### with

```kotlin
// with — 对对象执行多个操作（不是扩展函数）
val result = with(StringBuilder()) {
    append("Hello")
    append(", ")
    append("World")
    toString()  // 返回值
}
// result = "Hello, World"
```

### 作用域函数速查表

| 函数 | 对象引用 | 返回值 | 场景 |
|------|----------|--------|------|
| `let` | `it` | Lambda 结果 | 空安全操作、链式转换 |
| `apply` | `this` | 对象本身 | 对象配置/初始化 |
| `also` | `it` | 对象本身 | 附加操作（日志、验证） |
| `run` | `this` | Lambda 结果 | 执行计算并返回结果 |
| `with` | `this` | Lambda 结果 | 对对象执行多步操作 |

> **前端类比**：`apply` ≈ JS 的 `Object.assign()` 或 `Object.create()` + 属性设置，`let` ≈ 可选链后的操作。

## 五、内联函数（inline）

高阶函数会创建额外的对象（Lambda），`inline` 可以消除这个开销：

```kotlin
// 普通高阶函数 — 每次调用创建 Lambda 对象
fun doSomething(action: () -> Unit) {
    action()
}

// 内联函数 — 编译时把 Lambda 代码直接嵌入调用处
inline fun doSomethingInline(action: () -> Unit) {
    action()
}

// Kotlin 标准库的高阶函数大多是 inline 的
// 如 let, apply, also, run, with, filter, map 等
```

### reified — 内联函数中的具体化类型参数

```kotlin
// 普通泛型在运行时被擦除，不能检查类型
// inline + reified 可以保留类型信息
inline fun <reified T> Gson.fromJson(json: String): T {
    return fromJson(json, T::class.java)
}

// 使用
val user: User = gson.fromJson("""{"name":"张三"}""")
// 不需要传 Class 对象了
```

## 六、实用示例

### 自定义集合操作

```kotlin
// 扩展函数 + 高阶函数
inline fun <T> List<T>.filterNotNull(): List<T> {
    return filter { it != null }
}

fun <T, R> List<T>.mapIndexed(transform: (index: Int, T) -> R): List<R> {
    return mapIndexed { i, v -> transform(i, v) }
}
```

### Android 中的典型用法

```kotlin
// 点击事件
button.setOnClickListener {
    // Lambda 简化写法
    handleClick()
}

// 替代 Java 匿名内部类
// Java 写法:
// button.setOnClickListener(new View.OnClickListener() {
//     @Override
//     public void onClick(View v) {
//         handleClick();
//     }
// });

// RecyclerView Adapter
class MyAdapter : RecyclerView.Adapter<MyViewHolder>() {
    var items: List<Item> = emptyList()
        set(value) {
            field = value
            notifyDataSetChanged()
        }

    override fun onBindViewHolder(holder: MyViewHolder, position: Int) {
        holder.bind(items[position])
    }
}
```
