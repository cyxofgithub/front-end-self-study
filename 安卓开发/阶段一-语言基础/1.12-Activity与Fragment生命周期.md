# 1.12 Activity 与 Fragment 生命周期

> 理解 Android 中页面（Activity）和页面片段（Fragment）的完整生命周期。

---

## 一、Activity 生命周期

### 生命周期图

```
                  应用启动
                    │
                    ▼
              ┌───────────┐
              │ onCreate() │  ← 创建：初始化布局和数据
              └─────┬──────┘
                    │
                    ▼
              ┌───────────┐
              │ onStart()  │  ← 可见但不可交互
              └─────┬──────┘
                    │
                    ▼
              ┌────────────┐
              │ onResume()  │  ← 前台运行，可交互
              └─────┬───────┘
                    │
              ╔═══════════╗
              ║  运行中   ║
              ╚═════╤═════╝
                    │
              ┌─────┴───────┐
              │ onPause()   │  ← 失去焦点（如弹出对话框、切到其他页面）
              └─────┬───────┘
                    │
              ┌─────┴───────┐
              │ onStop()    │  ← 完全不可见（如切到其他应用）
              └─────┬───────┘
                    │
              ┌─────┴─────────┐
              │ onDestroy()   │  ← 被销毁（如调用 finish() 或系统回收）
              └───────────────┘
```

### 各回调说明

| 回调 | 触发时机 | 典型操作 |
|------|----------|----------|
| `onCreate()` | Activity 第一次创建 | `setContentView()` 设置布局，初始化变量 |
| `onStart()` | Activity 即将可见 | 注册广播、启动动画 |
| `onResume()` | Activity 获得焦点，可交互 | 开始相机预览、恢复播放 |
| `onPause()` | Activity 失去焦点 | 暂停动画、保存草稿数据 |
| `onStop()` | Activity 完全不可见 | 释放不需要的资源、注销广播 |
| `onDestroy()` | Activity 被销毁 | 清理所有资源、解除引用 |
| `onRestart()` | 从 onStop 回到前台 | 刷新数据 |

### 常见场景的生命周期流转

| 场景 | 回调序列 |
|------|----------|
| 打开页面 | onCreate → onStart → onResume |
| 按返回键退出 | onPause → onStop → onDestroy |
| 打开另一个页面 | onPause → onStop |
| 从另一个页面返回 | onRestart → onStart → onResume |
| 打开对话框 | onPause →（关闭）→ onResume |
| 旋转屏幕 | onPause → onStop → onDestroy → onCreate → onStart → onResume |
| 切到后台 | onPause → onStop |
| 从后台回来 | onRestart → onStart → onResume |

### 前端类比

```
Activity 生命周期       React 生命周期类比
─────────────────      ─────────────────
onCreate()         ≈   constructor + componentDidMount
onStart()          ≈   （进入 viewport）
onResume()         ≈   （获得焦点，可交互）
onPause()          ≈   （失去焦点）
onStop()           ≈   （离开 viewport）
onDestroy()        ≈   componentWillUnmount
onRestart()        ≈   （重新可见）
```

### 代码示例

```kotlin
class MainActivity : AppCompatActivity() {
    private val TAG = "MainActivity"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        Log.d(TAG, "onCreate")
        // 初始化视图和数据
    }

    override fun onStart() {
        super.onStart()
        Log.d(TAG, "onStart")
    }

    override fun onResume() {
        super.onResume()
        Log.d(TAG, "onResume")
    }

    override fun onPause() {
        super.onPause()
        Log.d(TAG, "onPause")
        // 保存临时数据
    }

    override fun onStop() {
        super.onStop()
        Log.d(TAG, "onStop")
    }

    override fun onDestroy() {
        super.onDestroy()
        Log.d(TAG, "onDestroy")
        // 释放资源
    }
}
```

## 二、Fragment 生命周期

Fragment 是 Activity 中的模块化 UI 片段，有自己的生命周期，但依附于宿主 Activity。

### 生命周期图

```
onAttach()           → 关联到宿主 Activity
  │
onCreate()           → 创建 Fragment
  │
onCreateView()       → 创建 Fragment 的视图（返回布局）
  │
onViewCreated()      → 视图创建完成，初始化视图组件
  │
onStart()            → 可见
  │
onResume()           → 可交互
  │
═════════════════════  运行中
  │
onPause()            → 失去焦点
  │
onStop()             → 不可见
  │
onDestroyView()      → 视图被销毁（Fragment 实例可能还在）
  │
onDestroy()          → Fragment 被销毁
  │
onDetach()           → 与 Activity 解除关联
```

### Fragment 生命周期的特殊性

Fragment 比 Activity 多了几个关键回调：

| 回调 | 说明 |
|------|------|
| `onAttach()` | Fragment 关联到 Activity |
| `onCreateView()` | 创建并返回 Fragment 的布局视图 |
| `onViewCreated()` | 视图创建完毕，可以安全地 `findViewById` |
| `onDestroyView()` | 视图被销毁，但 Fragment 实例可能还在（ViewPager 场景） |

### ViewPager 中的 Fragment

ViewPager（类似轮播/Tab 切换）中的 Fragment 有一个特殊行为：

```
ViewPager 中的 Fragment 生命周期：
                    添加 Fragment
                         │
                    onCreateView
                    onViewCreated
                    onStart → onResume
                         │
                     ╔═════════╗
                  用户滑到其他页  →  如果超出缓存范围
                     ╚═══╤═════╝
                         │
                    onDestroyView    ← 视图销毁
                    （但 Fragment 对象保留在内存中）
                         │
                  用户滑回来
                         │
                    onCreateView     ← 视图重新创建
                    onViewCreated
```

> **重要**：在 ViewPager 中，Fragment 的视图可能被多次创建和销毁。所以初始化逻辑要放在 `onViewCreated` 中而不是 `onCreate` 中。

## 三、onSaveInstanceState

当系统可能销毁并重建 Activity 时（如旋转屏幕、内存不足），系统会调用 `onSaveInstanceState` 保存状态：

```kotlin
override fun onSaveInstanceState(outState: Bundle) {
    super.onSaveInstanceState(outState)
    outState.putString("key_text", editText.text.toString())
    outState.putInt("key_position", scrollPosition)
}

override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    setContentView(R.layout.activity_main)

    if (savedInstanceState != null) {
        // 恢复之前保存的状态
        val text = savedInstanceState.getString("key_text", "")
        val position = savedInstanceState.getInt("key_position", 0)
    }
}
```

> **前端类比**：类似 React 的状态持久化或 URL query 参数保存页面状态。旋转屏幕 = 整个页面重新加载，需要从保存的状态中恢复。

## 四、Lifecycle 感知组件

Android 提供了 `Lifecycle` 组件，可以观察 Activity/Fragment 的生命周期事件：

```kotlin
class MyObserver : LifecycleObserver {

    @OnLifecycleEvent(Lifecycle.Event.ON_RESUME)
    fun onResume() {
        // Activity/Fragment onResume 时自动调用
        startListening()
    }

    @OnLifecycleEvent(Lifecycle.Event.ON_PAUSE)
    fun onPause() {
        stopListening()
    }
}

// 在 Activity/Fragment 中注册
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        lifecycle.addObserver(MyObserver())
    }
}
```

## 参考答案

### 第 1 题

```kotlin
// LifecycleActivity.kt
class LifecycleActivity : AppCompatActivity() {
    private val TAG = "LifecycleDemo"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_lifecycle)
        Log.d(TAG, "onCreate")
    }

    override fun onStart() {
        super.onStart()
        Log.d(TAG, "onStart")
    }

    override fun onResume() {
        super.onResume()
        Log.d(TAG, "onResume")
    }

    override fun onPause() {
        super.onPause()
        Log.d(TAG, "onPause")
    }

    override fun onStop() {
        super.onStop()
        Log.d(TAG, "onStop")
    }

    override fun onRestart() {
        super.onRestart()
        Log.d(TAG, "onRestart")
    }

    override fun onDestroy() {
        super.onDestroy()
        Log.d(TAG, "onDestroy")
    }
}
```

预期日志输出：
- 打开 → 按返回键：`onCreate → onStart → onResume → onPause → onStop → onDestroy`
- 打开 → 切后台 → 回前台：`onCreate → onStart → onResume → onPause → onStop → onRestart → onStart → onResume`
- 打开 → 旋转屏幕：`onCreate → onStart → onResume → onPause → onStop → onDestroy → onCreate → onStart → onResume`

### 第 2 题

```kotlin
// FirstActivity.kt
class FirstActivity : AppCompatActivity() {
    private val TAG = "FirstActivity"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_first)
        Log.d(TAG, "onCreate")

        findViewById<Button>(R.id.btnGoSecond).setOnClickListener {
            startActivity(Intent(this, SecondActivity::class.java))
        }
    }

    override fun onPause() { super.onPause(); Log.d(TAG, "onPause") }
    override fun onStop() { super.onStop(); Log.d(TAG, "onStop") }
    override fun onRestart() { super.onRestart(); Log.d(TAG, "onRestart") }
    override fun onResume() { super.onResume(); Log.d(TAG, "onResume") }
}

// SecondActivity.kt
class SecondActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_second)
    }
}
```

跳转时 FirstActivity 日志：`onPause → onStop`；按返回键回来时：`onRestart → onStart → onResume`

### 第 3 题

```kotlin
// MyFragment.kt
class MyFragment : Fragment() {

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View? {
        return inflater.inflate(R.layout.fragment_my, container, false)
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        view.findViewById<Button>(R.id.btnClick).setOnClickListener {
            Toast.makeText(requireContext(), "按钮被点击", Toast.LENGTH_SHORT).show()
        }
    }
}
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| Activity 生命周期 | `onCreate → onStart → onResume → onPause → onStop → onDestroy` |
| 各回调时机 | `onCreate` 初始化；`onResume` 可交互；`onPause` 保存临时数据；`onDestroy` 释放资源 |
| Fragment 生命周期 | 比 Activity 多 `onAttach`/`onCreateView`/`onViewCreated`/`onDestroyView`/`onDetach` |
| Fragment 视图重建 | ViewPager 中 Fragment 视图可能被多次创建/销毁；初始化放 `onViewCreated` |
| onSaveInstanceState | 旋转屏幕等场景保存状态；在 `onCreate` 中通过 `savedInstanceState` 恢复 |
| 常见场景流转 | 跳转页面：`onPause → onStop`；旋转屏幕：完整销毁重建；按返回：完整销毁 |
