# 1.7 Kotlin 类与对象

> 掌握 Kotlin 中类的定义、构造函数、data class 和 object 单例。

---

## 一、类定义与构造函数

### 主构造函数

```kotlin
// 主构造函数直接跟在类名后面
class User(val name: String, var age: Int)

// 等价于 Java 中：
// public class User {
//     private String name;
//     private int age;
//     public User(String name, int age) { this.name = name; this.age = age; }
//     public String getName() { return name; }
//     public void setAge(int age) { this.age = age; }
// }

// 使用
val user = User("张三", 25)
println(user.name)   // 张三
user.age = 26         // var 可修改
```

**`val` vs `var` 在构造函数中的区别**：
- `val name` → 生成只读属性（只有 getter）
- `var age` → 生成可变属性（getter + setter）
- 不加 `val`/`var` → 只在 init 块中可用，不成为属性

### init 块

```kotlin
class User(val name: String, var age: Int) {
    init {
        // 主构造函数的初始化逻辑
        require(age >= 0) { "年龄不能为负数" }
        println("创建了用户: $name")
    }
}
```

> **前端类比**：`init` 块 ≈ JS class 的 `constructor` 中的初始化逻辑。

### 次构造函数

```kotlin
class User(val name: String, var age: Int) {
    var email: String = ""

    // 次构造函数必须委托给主构造函数
    constructor(name: String, age: Int, email: String) : this(name, age) {
        this.email = email
    }
}

val u1 = User("张三", 25)
val u2 = User("李四", 30, "lisi@example.com")
```

## 二、属性与自定义 getter/setter

```kotlin
class Rectangle(val width: Int, val height: Int) {
    // 计算属性 — 自定义 getter
    val area: Int
        get() = width * height

    // 可变属性 + 自定义 setter
    var description: String = ""
        set(value) {
            field = value  // field 是幕后字段（backing field）
            println("描述已更新为: $value")
        }
}

val rect = Rectangle(10, 20)
println(rect.area)  // 200（每次访问时计算）

rect.description = "大矩形"  // 输出：描述已更新为: 大矩形
```

> **前端类比**：自定义 getter ≈ JS 的 `get` 访问器，`field` ≈ JS 中用 `_` 私有字段存储实际值。

## 三、data class

`data class` 自动生成 `equals()`、`hashCode()`、`toString()`、`copy()`、`componentN()`：

```kotlin
data class Article(
    val id: Int,
    val title: String,
    val author: String,
    val content: String = ""   // 可以有默认值
)

// toString
val article = Article(1, "Kotlin入门", "张三")
println(article)
// Article(id=1, title=Kotlin入门, author=张三, content=)

// equals — 按值比较
val a1 = Article(1, "Kotlin入门", "张三")
val a2 = Article(1, "Kotlin入门", "张三")
println(a1 == a2)  // true（data class 按值比较，不像 Java 按引用）

// copy — 复制并修改部分字段
val copied = article.copy(title = "Kotlin进阶")
// Article(id=1, title=Kotlin进阶, author=张三, content=)

// 解构声明
val (id, title, author, _) = article  // _ 跳过不需要的字段
```

### 前端类比

```typescript
// TS 中要实现类似功能需要大量代码
interface Article {
    id: number;
    title: string;
    author: string;
}
// 没有自动 equals、copy、解构等功能
```

**注意事项**：
- 主构造函数必须至少有一个参数
- 参数必须用 `val` 或 `var` 修饰
- 不能是 `abstract`、`open`、`sealed`、`inner`

## 四、object — 单例对象

### 对象声明（单例）

```kotlin
object DatabaseHelper {
    private var connection: String? = null

    fun connect(url: String) {
        connection = url
        println("连接到: $url")
    }

    fun disconnect() {
        connection = null
    }
}

// 使用 — 直接用类名调用，不需要实例化
DatabaseHelper.connect("localhost:3306")
DatabaseHelper.disconnect()
```

> **前端类比**：`object` ≈ JS 的单例模式（`const db = { connect() {}, disconnect() {} }`），但 Kotlin 保证线程安全和唯一实例。

### 伴生对象（companion object）

类内部的单例对象，类似 Java 的 `static`：

```kotlin
class User(val name: String) {
    companion object {
        private var count = 0

        fun create(name: String): User {
            count++
            return User(name)
        }

        fun getCount() = count
    }
}

val user = User.create("张三")   // 类似静态方法调用
println(User.getCount())         // 1
```

> **前端类比**：`companion object` ≈ JS class 的 `static` 方法。

### 对象表达式（匿名内部类）

```kotlin
// 类似 Java 的匿名内部类
val listener = object : OnClickListener {
    override fun onClick() {
        println("被点击了")
    }
}

// 也可以不继承任何类（纯匿名对象）
val config = object {
    val host = "localhost"
    val port = 8080
}
```

## 五、枚举类

```kotlin
enum class Direction {
    NORTH, SOUTH, EAST, WEST
}

// 带属性的枚举
enum class Status(val code: Int, val message: String) {
    SUCCESS(0, "成功"),
    LOADING(1, "加载中"),
    ERROR(-1, "失败");

    fun isSuccess() = this == SUCCESS
}

// 使用
val status = Status.SUCCESS
println(status.code)      // 0
println(status.message)   // 成功
status.isSuccess()         // true

// when 配合枚举（编译器会检查是否覆盖所有值）
fun handle(status: Status) = when (status) {
    Status.SUCCESS -> println("成功了")
    Status.LOADING -> println("加载中")
    Status.ERROR   -> println("出错了")
}
```

## 六、内联类（Inline Class）

```kotlin
// 包装一个值的类型安全容器，不产生额外对象开销
@JvmInline
value class UserId(val value: String)

@JvmInline
value class Email(val value: String)

fun sendTo(userId: UserId, email: Email) { /* ... */ }

// 不会传错参数
sendTo(UserId("123"), Email("test@example.com"))
// sendTo(Email("test@example.com"), UserId("123"))  // 编译错误
```

## 参考答案

### 第 1 题

```kotlin
data class Product(val id: Int, val name: String, val price: Double)

fun main() {
    val p1 = Product(1, "手机", 3999.0)
    val p2 = Product(2, "耳机", 299.0)
    val p3 = Product(3, "充电器", 99.0)

    println(p1)  // Product(id=1, name=手机, price=3999.0)

    // copy 修改价格
    val p1Discount = p1.copy(price = 3499.0)
    println(p1Discount)  // Product(id=1, name=手机, price=3499.0)

    // 解构
    val (id, name, price) = p2
    println("商品: $name, 价格: $price")
}
```

### 第 2 题

```kotlin
import java.text.SimpleDateFormat
import java.util.Date

object TimeUtils {
    private val formatter = SimpleDateFormat("yyyy-MM-dd HH:mm:ss")

    fun now(): String = formatter.format(Date())

    fun format(timestamp: Long): String = formatter.format(Date(timestamp))
}

// 使用
println(TimeUtils.now())                  // 2026-05-30 14:30:00
println(TimeUtils.format(1700000000000))  // 2023-11-14 22:13:20
```

### 第 3 题

```kotlin
class Logger {
    companion object {
        private const val TAG = "Logger"

        fun d(tag: String, msg: String) {
            println("[DEBUG] $tag: $msg")
        }

        fun e(tag: String, msg: String) {
            println("[ERROR] $tag: $msg")
        }
    }
}

// 使用
Logger.d("MainActivity", "页面创建完成")
Logger.e("Network", "请求失败")
```

### 第 4 题

```kotlin
enum class HttpStatus(val code: Int, val description: String) {
    OK(200, "OK"),
    NOT_FOUND(404, "Not Found"),
    INTERNAL_ERROR(500, "Internal Server Error");

    fun isSuccess(): Boolean = code in 200..299
}

// 使用
val status = HttpStatus.OK
println("${status.code} ${status.description}")  // 200 OK
println(status.isSuccess())                       // true

// when 匹配
fun handleStatus(status: HttpStatus) = when (status) {
    HttpStatus.OK -> println("请求成功")
    HttpStatus.NOT_FOUND -> println("资源未找到")
    HttpStatus.INTERNAL_ERROR -> println("服务器错误")
}
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| 主/次构造函数 | 主构造函数跟在类名后；`val`/`var` 决定是否成为属性；`init` 块做初始化 |
| 属性与 getter/setter | 自定义 getter 实现计算属性；`field` 幕后字段存储实际值 |
| data class | 自动生成 `equals`/`hashCode`/`toString`/`copy`/解构；必须至少一个 `val`/`var` 参数 |
| object 单例 | `object` 声明即单例，线程安全；直接用类名调用 |
| companion object | 类内部的单例，类似 Java `static`；可定义工厂方法 |
| 枚举类 | 可带属性和方法；配合 `when` 编译器强制穷举 |
| 内联类 | `@JvmInline value class`，零开销类型包装 |
