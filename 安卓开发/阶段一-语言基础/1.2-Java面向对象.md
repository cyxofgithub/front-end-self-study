# 1.2 Java 面向对象

> 理解 Java 的类、对象、封装、继承、多态——面向对象的四大核心概念。

---

## 一、类与对象

**类（Class）** 是对象的蓝图/模板，**对象（Object）** 是类的实例。

```java
// 定义类
public class User {
    // 字段（属性/成员变量）
    String name;
    int age;

    // 构造函数 — 创建对象时调用
    public User(String name, int age) {
        this.name = name;   // this 指向当前对象
        this.age = age;
    }

    // 方法（行为）
    public void sayHello() {
        System.out.println("你好，我是" + name + "，今年" + age + "岁");
    }
}

// 创建对象（实例化）
User user = new User("张三", 25);
user.sayHello();  // 输出：你好，我是张三，今年25岁
```

### 前端类比

```javascript
// JS 的 class（ES6）
class User {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
    sayHello() {
        console.log(`你好，我是${this.name}，今年${this.age}岁`);
    }
}
```

语法非常相似，但 Java 的 class 有访问控制（`public`/`private`/`protected`）。

### 构造函数重载

Java 支持多个构造函数（参数不同）：

```java
public class User {
    String name;
    int age;

    // 无参构造
    public User() {
        this.name = "匿名";
        this.age = 0;
    }

    // 全参构造
    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

User u1 = new User();            // 匿名, 0
User u2 = new User("张三", 25);   // 张三, 25
```

## 二、封装

**封装** = 隐藏内部实现细节，通过公开方法控制访问。

```java
public class BankAccount {
    private double balance;  // private — 外部不能直接访问

    public BankAccount(double initialBalance) {
        if (initialBalance >= 0) {
            this.balance = initialBalance;
        }
    }

    // getter — 只读访问
    public double getBalance() {
        return balance;
    }

    // setter — 带验证的写入
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
        }
    }
}
```

### 访问修饰符

| 修饰符 | 同类 | 同包 | 子类 | 其他包 |
|--------|:----:|:----:|:----:|:------:|
| `public` | ✅ | ✅ | ✅ | ✅ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| 默认（不写） | ✅ | ✅ | ❌ | ❌ |
| `private` | ✅ | ❌ | ❌ | ❌ |

> **前端类比**：JS/TS 的 `private`（`#` 前缀或 `private` 关键字）只在 TS 层面生效，Java 的 `private` 是 JVM 层面强制的。

## 三、继承

**继承** = 子类复用父类的字段和方法，并可以扩展。

```java
// 父类（基类）
public class Animal {
    protected String name;  // protected — 子类可访问

    public Animal(String name) {
        this.name = name;
    }

    public void eat() {
        System.out.println(name + "在吃东西");
    }
}

// 子类 — extends 关键字
public class Dog extends Animal {
    private String breed;

    public Dog(String name, String breed) {
        super(name);       // 调用父类构造函数，必须放在第一行
        this.breed = breed;
    }

    public void bark() {
        System.out.println(name + "在汪汪叫");
    }
}

Dog dog = new Dog("旺财", "柯基");
dog.eat();   // 继承自 Animal：旺财在吃东西
dog.bark();  // Dog 自己的方法：旺财在汪汪叫
```

### 关键规则

- Java **只支持单继承**（一个类只能 extends 一个父类）
- 子类构造函数必须调用 `super()`
- `final` 修饰的类不能被继承（类似 TS 的 `sealed`）

## 四、多态

**多态** = 同一个方法调用，不同对象有不同的行为。

### 方法重写（Override）

```java
public class Animal {
    public String sound() {
        return "动物叫声";
    }
}

public class Dog extends Animal {
    @Override  // 注解，表示重写父类方法
    public String sound() {
        return "汪汪汪";
    }
}

public class Cat extends Animal {
    @Override
    public String sound() {
        return "喵喵喵";
    }
}
```

### 多态的使用

```java
// 父类引用指向子类对象
Animal a1 = new Dog();
Animal a2 = new Cat();

a1.sound();  // 汪汪汪 — 运行时根据实际类型调用
a2.sound();  // 喵喵喵

// 数组中多态
Animal[] animals = { new Dog(), new Cat() };
for (Animal a : animals) {
    System.out.println(a.sound());  // 各自输出自己的叫声
}
```

### 方法重载（Overload）vs 重写（Override）

```java
// 重载（Overload）— 同名方法，参数不同（编译时多态）
public class Calculator {
    public int add(int a, int b) { return a + b; }
    public double add(double a, double b) { return a + b; }
    public int add(int a, int b, int c) { return a + b + c; }
}

// 重写（Override）— 子类覆盖父类方法（运行时多态）
// 见上面的 Animal / Dog / Cat 示例
```

> **前端类比**：重载类似 TS 的函数重载签名，重写类似子类覆盖父类方法。

## 五、类型转换与 instanceof

```java
Animal animal = new Dog();  // 向上转型（自动）

// 向下转型（需要强制转换，可能出错）
if (animal instanceof Dog) {       // 先检查类型
    Dog dog = (Dog) animal;         // 安全转型
    dog.bark();
}

// Java 16+ 模式匹配
if (animal instanceof Dog dog) {   // 检查 + 转型一步完成
    dog.bark();
}
```

> **前端类比**：`instanceof` 类似 JS 的 `instanceof`，转型类似 TS 的类型断言 `as Dog`。

## 六、Object 类

所有 Java 类都隐式继承自 `java.lang.Object`，它提供以下方法：

| 方法 | 用途 |
|------|------|
| `toString()` | 返回对象的字符串表示 |
| `equals(Object)` | 判断两个对象是否相等 |
| `hashCode()` | 返回哈希值（配合 HashMap 等） |
| `getClass()` | 获取运行时类信息 |

```java
// 重写 toString（打印对象时自动调用）
public class User {
    String name;
    int age;

    @Override
    public String toString() {
        return "User{name='" + name + "', age=" + age + "}";
    }
}

User user = new User();
user.name = "张三";
user.age = 25;
System.out.println(user);  // User{name='张三', age=25}
```
