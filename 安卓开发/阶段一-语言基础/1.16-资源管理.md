# 1.16 资源管理

> 理解 Android res 目录的结构和各类资源的使用方式。

---

## 一、res 目录结构

```
res/
├── drawable/          图片和矢量图形
│   ├── icon.png       位图
│   ├── bg_shape.xml   形状（类似 CSS 背景）
│   └── ic_arrow.xml   矢量图（VectorDrawable）
│
├── layout/            布局文件（XML）
│   ├── activity_main.xml
│   ├── fragment_home.xml
│   └── item_list.xml
│
├── values/            值资源
│   ├── strings.xml    字符串
│   ├── colors.xml     颜色
│   ├── dimens.xml     尺寸
│   ├── styles.xml     样式
│   └── themes.xml     主题
│
├── mipmap/            应用图标（不同分辨率）
│   ├── mipmap-mdpi/
│   ├── mipmap-hdpi/
│   ├── mipmap-xhdpi/
│   ├── mipmap-xxhdpi/
│   └── mipmap-xxxhdpi/
│
├── raw/               原始文件（音频、视频等）
│   └── notification.mp3
│
└── xml/               XML 配置文件
    └── preferences.xml
```

### 前端类比

```
Android 资源               前端项目
───────────               ──────────
res/layout/*.xml      ≈   *.vue / *.jsx（模板）
res/values/strings.xml ≈  locales/zh-CN.json（国际化）
res/values/colors.xml ≈   theme.css / CSS 变量
res/values/styles.xml ≈   全局样式 / CSS 类
res/drawable/         ≈   assets/images/
res/mipmap/           ≈   public/icons/（多尺寸 favicon）
```

## 二、字符串资源

### 定义

```xml
<!-- res/values/strings.xml -->
<resources>
    <string name="app_name">我的应用</string>
    <string name="welcome">欢迎, %1$s! 你有 %2$d 条消息</string>
    <string name="multi_line">第一行\n第二行</string>
</resources>
```

### 使用

```kotlin
// 代码中使用
val appName = getString(R.string.app_name)
val welcome = getString(R.string.welcome, "张三", 5)  // 欢迎, 张三! 你有 5 条消息

// XML 布局中使用
// <TextView android:text="@string/app_name" />
```

## 三、颜色资源

### 定义

```xml
<!-- res/values/colors.xml -->
<resources>
    <color name="primary">#FF6200EE</color>
    <color name="primary_dark">#FF3700B3</color>
    <color name="background">#FFFFFFFF</color>
    <color name="text_primary">#DE000000</color>  <!-- 87% 不透明度 -->
</resources>
```

### 使用

```kotlin
// 代码中
val color = ContextCompat.getColor(context, R.color.primary)
textView.setTextColor(color)

// XML 中
// android:textColor="@color/text_primary"
// android:background="@color/background"
```

## 四、尺寸资源

### 单位说明

| 单位 | 说明 | 使用场景 |
|------|------|----------|
| `dp` (density-independent pixels) | 密度无关像素 | 大部分尺寸（宽高、边距） |
| `sp` (scale-independent pixels) | 缩放无关像素 | 字体大小（跟随系统字体缩放） |
| `px` | 实际像素 | 不推荐使用 |

### 定义

```xml
<!-- res/values/dimens.xml -->
<resources>
    <dimen name="margin_small">8dp</dimen>
    <dimen name="margin_medium">16dp</dimen>
    <dimen name="margin_large">24dp</dimen>
    <dimen name="text_size_body">14sp</dimen>
    <dimen name="text_size_title">20sp</dimen>
</resources>
```

### 使用

```kotlin
// 代码中
val margin = resources.getDimensionPixelSize(R.dimen.margin_medium)

// XML 中
// android:layout_margin="@dimen/margin_medium"
// android:textSize="@dimen/text_size_body"
```

## 五、样式和主题

### 样式（Style）— 类似 CSS 类

```xml
<!-- res/values/styles.xml -->
<style name="TitleText">
    <item name="android:textSize">20sp</item>
    <item name="android:textColor">@color/text_primary</item>
    <item name="android:fontFamily">sans-serif-medium</item>
</style>

<style name="BodyText">
    <item name="android:textSize">14sp</item>
    <item name="android:textColor">@color/text_secondary</item>
    <item name="android:lineSpacingExtra">4dp</item>
</style>
```

```xml
<!-- XML 中使用 -->
<TextView
    style="@style/TitleText"
    android:text="标题" />
```

### 样式继承

```xml
<!-- 继承 TitleText 并覆盖颜色 -->
<style name="TitleText.Warning">
    <item name="android:textColor">@color/error</item>
</style>
```

### 主题（Theme）— 全局样式

```xml
<!-- res/values/themes.xml -->
<style name="AppTheme" parent="Theme.MaterialComponents.Light.DarkActionBar">
    <item name="colorPrimary">@color/primary</item>
    <item name="colorPrimaryDark">@color/primary_dark</item>
    <item name="colorAccent">@color/accent</item>
    <item name="android:windowBackground">@color/background</item>
</style>
```

```xml
<!-- AndroidManifest.xml 中应用主题 -->
<application
    android:theme="@style/AppTheme">
```

## 六、Drawable 资源

### Shape（形状）

```xml
<!-- res/drawable/bg_rounded.xml -->
<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <solid android:color="#FFFFFF" />
    <corners android:radius="12dp" />
    <stroke android:width="1dp" android:color="#E0E0E0" />
</shape>
```

```xml
<!-- 使用 -->
<View
    android:background="@drawable/bg_rounded" />
```

> **前端类比**：Shape ≈ CSS 的 `background`, `border-radius`, `border`。

### Selector（状态选择器）

```xml
<!-- res/drawable/btn_selector.xml -->
<selector xmlns:android="http://schemas.android.com/apk/res/android">
    <item android:state_pressed="true" android:drawable="@color/primary_dark" />
    <item android:state_enabled="false" android:drawable="@color/gray" />
    <item android:drawable="@color/primary" />
</selector>
```

> **前端类比**：Selector ≈ CSS 的 `:hover`, `:active`, `:disabled` 伪类。

### Layer List（图层叠加）

```xml
<!-- res/drawable/bg_shadow.xml -->
<layer-list xmlns:android="http://schemas.android.com/apk/res/android">
    <!-- 阴影层 -->
    <item android:top="2dp">
        <shape>
            <solid android:color="#20000000" />
            <corners android:radius="8dp" />
        </shape>
    </item>
    <!-- 内容层 -->
    <item android:bottom="2dp">
        <shape>
            <solid android:color="#FFFFFF" />
            <corners android:radius="8dp" />
        </shape>
    </item>
</layer-list>
```

## 七、屏幕适配

### 限定符目录

```
res/
├── values/              默认
├── values-land/         横屏
├── values-sw600dp/      最小宽度 600dp（7 寸平板）
├── values-sw720dp/      最小宽度 720dp（10 寸平板）
├── drawable-mdpi/       中密度屏幕
├── drawable-hdpi/       高密度屏幕
├── drawable-xhdpi/      超高密度屏幕
├── drawable-xxhdpi/     超超高密度屏幕
└── drawable-xxxhdpi/    超超超高密度屏幕
```

系统会根据设备参数自动选择最匹配的资源目录。

## 八、在代码中访问资源

```kotlin
// 通过 R 类访问资源
val string = getString(R.string.app_name)
val color = ContextCompat.getColor(this, R.color.primary)
val drawable = ContextCompat.getDrawable(this, R.drawable.icon)
val dimension = resources.getDimension(R.dimen.margin_medium)
val boolean = resources.getBoolean(R.bool.is_tablet)

// 动态获取资源 ID
val resId = resources.getIdentifier("icon_$index", "drawable", packageName)
```

## 本章知识点总结

| 知识点 | 要点 |
|--------|------|
| res 目录结构 | `drawable`（图形）/ `layout`（布局）/ `values`（值）/ `mipmap`（图标）/ `raw`（原始文件） |
| 字符串资源 | `strings.xml` 定义；`%1$s`/`%2$d` 格式化参数；支持国际化 |
| 颜色资源 | `colors.xml` 定义；支持透明度（8 位十六进制） |
| 尺寸单位 | `dp` 用于布局尺寸；`sp` 用于字体大小（跟随系统缩放） |
| 样式与主题 | Style ≈ CSS 类（单个组件）；Theme ≈ 全局 CSS 变量 |
| Shape | XML 定义形状（矩形/圆角/渐变等）；≈ CSS `border-radius` + `background` |
| Selector | 状态选择器（pressed/enabled/focused）；≈ CSS 伪类 |
| 屏幕适配 | 限定符目录（`values-sw600dp` 等）；系统自动选择最匹配资源 |
