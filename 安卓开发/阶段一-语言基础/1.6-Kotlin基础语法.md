# 1.6 Kotlin 基础语法

> Kotlin 是 Android 官方推荐语言，更简洁、更安全。本节覆盖 val/var、类型推断、空安全、函数定义。

---

## 一、val 与 var

```kotlin
val name = "张三"   // 只读变量（不可重新赋值），类似 Java final
var age = 25        // 可变变量

name = "李四"       // ❌ 编译错误：val 不能重新赋值
age = 26            // ✅ var 可以重新赋值
```

### 前端类比

```javascript
const name = "张三";  // ≈ Kotlin val
let age = 25;         // ≈ Kotlin var
```

**经验法则**：优先使用 `val`，只在需要修改时才用 `var`。

---

## 二、类型推断

Kotlin 编译器能自动推断变量类型，大多数时候不需要显式声明：

```kotlin
val message = "Hello"          // 推断为 String
val count = 42                 // 推断为 Int
val price = 9.99               // 推断为 Double
val isValid = true             // 推断为 Boolean
val list = listOf(1, 2, 3)    // 推断为 List<Int>

// 需要显式声明类型的场景
val name: String = "张三"            // 可以但没必要
val people: List<String> = emptyList()  // 空集合无法推断元素类型
```

## 三、空安全（核心特性）

Kotlin 在类型系统层面区分可空和不可空，**从源头消除 NullPointerException**。

### 可空类型

```kotlin
var name: String = "张三"     // 不可为 null
name = null                   // ❌ 编译错误

var nickname: String? = null  // 类型后加 ? 表示可空
nickname = null               // ✅ 允许
nickname = "小三"              // ✅ 也允许
```

### 安全调用操作符 `?.`

```kotlin
val len: Int? = nickname?.length
// 如果 nickname 为 null → 返回 null
// 如果 nickname 不为 null → 返回其 length
// 不会抛出 NullPointerException
```

### Elvis 操作符 `?:`

```kotlin
val len: Int = nickname?.length ?: 0
// 如果左边为 null → 使用右边的默认值
// 类似 JS 的 ??（空值合并运算符）

val displayName = nickname ?: "匿名用户"
```

### 非空断言 `!!`（谨慎使用）

```kotlin
val len: Int = nickname!!.length
// 如果 nickname 为 null → 抛出 KotlinNullPointerException
// 只有在你 100% 确定不为 null 时才使用
```

### 安全转换 `as?`

```kotlin
val obj: Any = "Hello"
val num: Int? = obj as? Int   // 转换失败返回 null，不抛异常
val str: String? = obj as? String  // "Hello"
```

### let 的空安全用法

```kotlin
nickname?.let {
    // 只有 nickname 不为 null 时才执行
    println("昵称长度: ${it.length}")
}
```

### 前端类比

```typescript
// TypeScript 可选链
nickname?.length      // 和 Kotlin 一模一样

// 空值合并
nickname ?? "匿名"    // ≈ Kotlin 的 ?:

// 但 Kotlin 的空安全是编译期强制的，TS 只是提示
```

## 四、函数定义

### 基本函数

```kotlin
// 标准写法
fun add(a: Int, b: Int): Int {
    return a + b
}

// 单表达式函数
fun add(a: Int, b: Int): Int = a + b

// 无返回值
fun greet(name: String): Unit {   // Unit 类似 Java void
    println("你好, $name")
}
// Unit 可以省略
fun greet(name: String) {
    println("你好, $name")
}
```

### 默认参数

```kotlin
fun greet(name: String, greeting: String = "你好") {
    println("$greeting, $name")
}

greet("张三")                    // 你好, 张三
greet("张三", "早上好")          // 早上好, 张三
```

### 命名参数

```kotlin
fun createUser(name: String, age: Int, city: String = "北京") {
    // ...
}

// 用命名参数可以跳过有默认值的参数，或者打乱顺序
createUser(name = "张三", age = 25)
createUser(age = 25, name = "张三", city = "上海")
```

> **前端类比**：Kotlin 的命名参数 ≈ JS 中解构传参 `{ name: "张三", age: 25 }`，但 Kotlin 是语言层面支持的。

### 字符串模板

```kotlin
val name = "张三"
val age = 25

// $变量名 — 简单引用
println("我叫$name")              // 我叫张三

// ${表达式} — 表达式引用
println("明年${age + 1}岁")       // 明年26岁

// 三引号字符串（raw string）
val text = """
    第一行
    第二行
    第三行
""".trimIndent()
```

> **前端类比**：`$name` ≈ JS 的 `${name}` 模板字符串，Kotlin 简单变量不需要花括号。

## 五、条件表达式

```kotlin
// if 是表达式（有返回值），不像 Java 只是语句
val max = if (a > b) a else b

// when 表达式（更强大的 switch）
fun describe(number: Int): String = when (number) {
    1 -> "一"
    2, 3 -> "二或三"
    in 4..10 -> "四到十"
    !in 11..20 -> "不在十一到二十之间"
    else -> "其他"
}

// when 类型检查
fun describe(obj: Any): String = when (obj) {
    is String -> "字符串: $obj"
    is Int -> "整数: $obj"
    else -> "未知类型"
}
```

## 六、循环

```kotlin
// for 循环
for (i in 1..5) {          // 1, 2, 3, 4, 5（包含两端）
    println(i)
}

for (i in 1 until 5) {     // 1, 2, 3, 4（不包含 5）
    println(i)
}

for (i in 10 downTo 1 step 2) {  // 10, 8, 6, 4, 2
    println(i)
}

// 遍历集合
val fruits = listOf("苹果", "香蕉", "橙子")
for ((index, fruit) in fruits.withIndex()) {
    println("$index: $fruit")
}

// while / do-while — 与 Java 一致
```

---

## 七、类型检查与转换

```kotlin
// is — 类型检查（类似 Java instanceof）
if (obj is String) {
    // 自动智能转换（不需要手动 cast）
    println(obj.length)  // obj 自动被当作 String
}

// as — 不安全转换
val str: String = obj as String    // 如果 obj 不是 String，抛异常

// as? — 安全转换
val str: String? = obj as? String  // 转换失败返回 null
```
