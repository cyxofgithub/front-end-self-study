## mcp 三大用途

-   提供工具调用
-   管理提示词模板
-   资源访问

**能力对比与应用价值**
| 能力 | 核心目标 | 关键优势 | 安全机制 |
| ---------- | ------------------------ | -------------------------- | ---------------------- |
| 工具调用 | 扩展模型 "执行" 能力 | 一次开发、多模型复用 | 权限审批 + 审计跟踪 |
| 资源访问 | 丰富模型 "感知" 能力 | 数据本地留存 + 格式统一 | 只读隔离 + 加密传输 |
| 提示词编排 | 提升模型 "思考" 效率 | 精准引导 + 节省 Token | 模板权限控制 |

**核心作用与延伸价值**
打破数据孤岛：统一接口让模型无缝访问实时数据 / 私有资源，无需为每个工具单独开发适配代码。
降低开发成本：开发者只需实现一次 MCP Server，所有兼容 MCP 的模型均可调用，减少重复工作。
增强安全合规：内置权限控制与数据加密，敏感数据无需全量上传至模型端，符合隐私保护要求。
适配自主 Agent：支持以 Agent 为中心的主动工作流，模型可自主选择工具、编排步骤，完成复杂任务。

**快速理解示例**
智能旅行助手：通过资源访问读取用户行程表，用工具调用预订机票 / 酒店，用提示词编排生成个性化行程建议，全程标准化交互且数据安全可控。
