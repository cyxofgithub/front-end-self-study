## 讲一下盒子模型

盒子模型一般就分标准的盒模型（content-box）和替代/IE 盒模型（border-box）。

### 区别

- content-box（标准盒模型）：`width`/`height` 只包含 content，实际渲染宽度 = width + padding + border + margin。
- border-box（怪异/IE 盒模型）：`width`/`height` 包含 content + padding + border，实际渲染宽度 = width + margin。

盒子模型可以通过 box-sizing 切换，有三个属性：content-box 丨 border-box 丨 inherit，分别对应标准的盒子模型、IE/替代盒子模型，继承父类的 box-sizing 属性。

### 使用场景

- content-box：
    - 需要精确控制内容区尺寸的场景，如文章正文、文字排版，保证内容区宽度固定、阅读体验稳定；
    - 作为浏览器默认值，兼容性最好，适合偏文档流的传统布局。

- border-box：
    - 现代 CSS 布局（Flex / Grid）下推荐全局使用，`width` 即盒子最终可见宽度，设置 padding / border 不会把盒子撑大，计算直观、不易出错；
    - 栅格系统、组件库（如 Bootstrap、Element）中，设百分比宽度再叠加 padding 时不会溢出容器；
    - 响应式布局里写 `width: 100%` 加 padding 不会撑破父容器。

工程上常全局统一为 border-box：

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```
