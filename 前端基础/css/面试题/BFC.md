BFC（Block Formatting Context，块级格式化上下文）是 CSS 中独立的渲染区域，内部元素布局与外部隔离，遵循自身规则，能解决 margin 重叠、浮动高度塌陷等布局问题。以下从核心要点、触发条件、特性、应用场景展开说明：

### 核心要点

BFC 是浏览器渲染时创建的封闭布局容器，内部子元素的布局不会影响外部元素，外部元素也不会影响内部，以此实现布局的独立性和可预测性。它不是 CSS 属性，而是元素满足特定条件后浏览器赋予的渲染特性。

### 触发条件

满足以下任一条件即可触发 BFC：
|触发条件|具体属性值|
| ---- | ---- |
|浮动元素|float: left/right（不为 none）|
|定位元素|position: absolute/fixed|
|特定 display 值|display: inline - block/table - cell/flex/grid/table - caption|
|overflow 属性|overflow: hidden/auto/scroll（不为 visible）|
|根元素|html 根元素默认创建 BFC|

### 核心特性

1.  垂直排列：BFC 内块级盒子沿垂直方向按文档流顺序排列，垂直间距由 margin 决定。
2.  外边距折叠：同一 BFC 中，相邻块级盒子垂直外边距会折叠，取较大值；不同 BFC 间不会折叠。
3.  隔离浮动：BFC 区域不与浮动元素重叠，计算 BFC 高度时，浮动元素也会被计入，可避免高度塌陷。
4.  边界约束：BFC 内元素左外边界紧挨着包含块左边（从左往右排版），即使存在浮动元素。

### 典型应用场景

1.  **解决 margin 重叠**：将相邻元素放入不同 BFC 容器，避免垂直 margin 折叠。例如两个相邻 div，给其中一个外层套一个触发 BFC 的容器。
2.  **清除浮动**（防止高度塌陷）：父元素触发 BFC，可包含内部浮动子元素，正确计算自身高度。如父元素设置 overflow: hidden。
3.  实现自适应两栏布局：左侧元素浮动，右侧元素触发 BFC，右侧会自动占满剩余宽度且不与左侧重叠。
4.  避免元素被浮动元素覆盖：给被覆盖元素触发 BFC，使其布局不受浮动元素干扰。

---

### 总结

BFC 的核心价值在于提供布局隔离能力，通过特定条件触发后，可规范内部元素布局并阻断与外部的布局干扰，是解决 CSS 布局常见问题的关键机制，也是前端面试高频考点。
