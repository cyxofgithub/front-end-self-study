## HTTP 与 HTTPS 区别

一句话结论：HTTPS = HTTP + SSL/TLS，在 HTTP 基础上增加了加密、认证和完整性保护，代价是额外的握手开销和服务器资源消耗。

| 对比维度 | HTTP | HTTPS |
|---|---|---|
| 协议构成 | HTTP over TCP | HTTP over SSL/TLS over TCP |
| 默认端口 | 80 | 443 |
| 数据传输 | 明文传输，无加密 | 加密传输，防窃听、防篡改 |
| 证书要求 | 无需证书 | 需向 CA 申请数字证书 |
| 连接开销（握手包数） | TCP 三次握手：3 个包 | TCP 三次握手 + SSL/TLS 握手：约 12 个包 |
| 页面响应速度 | 较快 | 较慢（额外握手 + 加解密计算） |
| 服务器资源消耗 | 较低 | 较高（加解密运算开销） |
| 安全性 | 低 | 高 |

### 补充

- HTTPS 的加密依赖 SSL/TLS 协议，主要提供 **通信加密**、**身份认证**（证书）和 **数据完整性校验** 三方面保障。
- 现代 HTTPS 使用 TLS 1.3 可将握手包数从 12 个优化到 **约 4-6 个**（1-RTT 或 0-RTT），实际性能差距已大幅缩小。
