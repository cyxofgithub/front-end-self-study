### 一、核心场景说明

我们以最常用的“左侧 200px + 中间自适应 + 右侧 200px”为例，这是实际开发中最常见的三列布局需求（比如左侧导航、中间内容、右侧侧边栏）。

### 二、具体实现方式

#### 1. 传统方案：浮动（Float）实现

这是早期 CSS 布局的经典方案，兼容性极好（支持所有浏览器），但需要处理浮动清除问题。

```css
/* 父容器：清除浮动，避免高度塌陷 */
.container {
    width: 100%;
    height: 400px;
    border: 1px solid #ccc;
    /* 清除浮动的核心：BFC（块级格式化上下文） */
    overflow: hidden;
}

/* 左列：定宽+左浮动 */
.left {
    width: 200px;
    height: 100%;
    background: #f0f8ff;
    float: left;
}

/* 右列：定宽+右浮动 */
.right {
    width: 200px;
    height: 100%;
    background: #fdf2f8;
    float: right;
}

/* 中间列：通过margin留出左右空间，实现自适应 */
.middle {
    height: 100%;
    background: #f5f5f5;
    /* 关键：margin左右值等于左右列的宽度 */
    margin: 0 200px;
}
```

```html
<div class="container">
    <div class="left">左列（200px）</div>
    <div class="right">右列（200px）</div>
    <!-- 注意：中间列必须放在最后 -->
    <div class="middle">中间列（自适应）</div>
</div>
```

**关键说明**：

-   左右列通过`float`脱离文档流，中间列通过`margin`避开左右列的位置；
-   必须给父容器清除浮动（比如`overflow: hidden`），否则父容器会高度塌陷；
-   中间列的 HTML 结构必须放在左右列之后，这是该方案的局限性。

#### 2. 传统方案：定位（Position）实现

通过绝对定位实现，逻辑简单，但列会脱离文档流，可能影响后续元素布局。

```css
.container {
    width: 100%;
    height: 400px;
    border: 1px solid #ccc;
    /* 父容器相对定位，作为子元素绝对定位的参考 */
    position: relative;
}

.left {
    width: 200px;
    height: 100%;
    background: #f0f8ff;
    /* 绝对定位到左侧 */
    position: absolute;
    left: 0;
    top: 0;
}

.right {
    width: 200px;
    height: 100%;
    background: #fdf2f8;
    /* 绝对定位到右侧 */
    position: absolute;
    right: 0;
    top: 0;
}

.middle {
    height: 100%;
    background: #f5f5f5;
    /* 同样通过margin留出空间 */
    margin: 0 200px;
}
```

```html
<div class="container">
    <div class="left">左列（200px）</div>
    <div class="middle">中间列（自适应）</div>
    <div class="right">右列（200px）</div>
</div>
```

**关键说明**：

-   父容器必须设置`position: relative`，否则子元素的绝对定位会相对于整个页面；
-   左右列脱离文档流，不会占据空间，因此中间列需要用`margin`留出位置；
-   缺点：如果列的高度不一致，不会自动撑开父容器，布局容易错乱。

#### 3. 现代主流：Flexbox（弹性盒）实现

这是目前**最推荐**的方案，语法简洁、灵活，适配性极好，是现代前端布局的首选。

```css
.container {
    width: 100%;
    height: 400px;
    border: 1px solid #ccc;
    /* 核心：开启弹性盒布局 */
    display: flex;
}

.left {
    /* 定宽：直接设置width */
    width: 200px;
    height: 100%;
    background: #f0f8ff;
}

/* 核心：中间列设置flex: 1，自动占满剩余空间 */
.middle {
    flex: 1;
    height: 100%;
    background: #f5f5f5;
}

.right {
    width: 200px;
    height: 100%;
    background: #fdf2f8;
}
```

```html
<div class="container">
    <div class="left">左列（200px）</div>
    <div class="middle">中间列（自适应）</div>
    <div class="right">右列（200px）</div>
</div>
```

**关键说明**：

-   父容器设置`display: flex`后，子元素会自动水平排列；
-   `flex: 1` 等价于 `flex-grow: 1`，表示“占满剩余所有空间”；
-   优点：HTML 结构无顺序要求、可轻松实现垂直居中、自适应能力强，几乎无兼容性问题（支持 IE10+及所有现代浏览器）。

#### 4. 进阶方案：Grid（网格）实现

专为二维布局设计，代码最简洁，适合复杂布局场景，是未来布局的趋势。

```css
.container {
    width: 100%;
    height: 400px;
    border: 1px solid #ccc;
    /* 核心：开启网格布局 */
    display: grid;
    /* 定义列宽：200px + 自适应 + 200px */
    grid-template-columns: 200px 1fr 200px;
    /* 1fr 表示“剩余空间的1份”，类似flex: 1 */
}

.left {
    background: #f0f8ff;
}

.middle {
    background: #f5f5f5;
}

.right {
    background: #fdf2f8;
}
```

```html
<div class="container">
    <div class="left">左列（200px）</div>
    <div class="middle">中间列（自适应）</div>
    <div class="right">右列（200px）</div>
</div>
```

**关键说明**：

-   `grid-template-columns` 直接定义列的宽度，语法极其简洁；
-   `1fr` 是网格布局的弹性单位，自动分配剩余空间；
-   优点：适合更复杂的二维布局（比如多行多列），代码量最少；
-   兼容性：支持 IE11+及所有现代浏览器。

### 三、各方案对比

| 实现方式 | 优点                       | 缺点                         | 适用场景                     |
| -------- | -------------------------- | ---------------------------- | ---------------------------- |
| 浮动     | 兼容性极好（IE6+）         | 需要清除浮动、结构有顺序要求 | 兼容老旧浏览器的项目         |
| 定位     | 逻辑简单、实现快           | 脱离文档流、布局易错乱       | 简单静态布局                 |
| Flexbox  | 灵活、简洁、适配性强       | IE9 及以下不支持             | 绝大多数现代前端项目（推荐） |
| Grid     | 语法极简、支持复杂二维布局 | IE10 及以下支持差            | 复杂布局、现代浏览器项目     |

### 总结

1. **首选方案**：日常开发优先使用 **Flexbox（弹性盒）**，兼顾简洁性和兼容性，是三列布局的最优解；
2. **特殊场景**：需要兼容极老旧浏览器（如 IE6/7）用浮动，复杂二维布局用 Grid；
3. **核心逻辑**：三列布局的关键是“定宽列占固定空间，自适应列占剩余空间”，Flex/Grid 通过原生属性实现，比传统方案更优雅。
