## H5 唤起 APP 失败

-   现象：点击 “打开 APP” 按钮，部分设备 / 浏览器无法唤起，或无 fallback 方案。
-   原因：不同浏览器对唤起协议（如 scheme/app link）的支持不同，未处理唤起失败的情况。
-   解决方案：
    -   核心：先尝试唤起 APP（scheme 协议），超时后跳转下载页

```javascript
function openApp() {
    // 尝试唤起APP
    const iframe = document.createElement('iframe');
    iframe.src = 'appscheme://xxx'; // 替换为实际的scheme
    iframe.style.display = 'none';
    document.body.appendChild(iframe);

    // 超时未唤起则跳转下载页
    setTimeout(() => {
        window.location.href = 'https://xxx.com/download';
    }, 2000);
}
```

    -   微信内唤起：需接入微信开放平台的 “APP 跳转” 能力。

## h5 微信分享样式异常

-   现象：H5 分享到微信后，标题、描述、封面图不显示或错误。
-   原因：未配置微信 JSSDK 的分享参数，或参数配置错误。
-   解决方案：
    -   接入微信 JSSDK，配置 wx.config 和 wx.ready 中的分享参数：

```javascript
wx.ready(() => {
    wx.updateAppMessageShareData({
        // 分享给好友
        title: '标题',
        desc: '描述',
        link: '页面链接',
        imgUrl: '封面图链接',
        success: () => {},
    });
});
```
