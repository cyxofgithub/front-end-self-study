# 图片适配方案

## 一、srcset + sizes 属性（适配同图不同尺寸）

`srcset` 是 `<img>` 标签的属性，核心作用是为**同一张图片**提供不同尺寸/像素密度的版本，让浏览器自动选择最优的加载；`sizes` 则配合宽度描述符，告诉浏览器图片在页面中会显示的宽度，辅助计算选择。

### 1. 像素密度描述符（x）：适配 Retina 屏

适合为不同像素密度的屏幕（如普通屏 1x、Retina 屏 2x/3x）提供不同清晰度的图片。

```html
<!-- 浏览器根据屏幕像素密度选择：1x屏加载small.jpg，2x屏加载medium.jpg，3x屏加载large.jpg -->
<img src="images/small.jpg" <!-- 降级方案：不支持srcset的浏览器加载此图 -- />
srcset="images/small.jpg 1x, images/medium.jpg 2x, images/large.jpg 3x" alt="响应式图片示例" >
```

### 2. 宽度描述符（w）+ sizes：适配不同视口宽度

适合根据屏幕宽度（如手机、平板、桌面）加载不同尺寸的图片，是更常用的响应式场景。

```html
<!-- 核心逻辑：
  1. sizes：告诉浏览器「图片在不同视口下的显示宽度」
     - 视口≤600px时，图片显示宽度为100vw（占满屏幕）
     - 其他情况，图片显示宽度为800px
  2. srcset：提供不同宽度的图片资源，浏览器根据sizes计算后选择最优的加载
-->
<img src="images/400w.jpg" <!-- 降级方案 -- />
srcset="images/400w.jpg 400w, images/800w.jpg 800w, images/1200w.jpg 1200w" sizes="(max-width: 600px) 100vw, 800px"
alt="响应式图片示例" >
```

**关键解释**：

-   `400w`/`800w`：表示图片的实际宽度（不是显示宽度），单位`w`是宽度描述符；
-   `sizes` 只描述「图片的显示宽度规则」，不决定图片的实际加载尺寸，最终由浏览器根据「显示宽度 + 屏幕像素密度」选择 srcset 中的图片；
-   必须保留`src`属性，作为不支持`srcset`的老旧浏览器的降级方案。

---

## 二、<picture>标签（适配不同图片/格式）

`<picture>` 是一个容器标签，内部包含多个`<source>`标签和一个`<img>`标签，核心优势是：

-   支持为不同场景（如不同视口、不同设备）加载**不同内容/比例**的图片；
-   支持优先加载更优的图片格式（如 WebP，体积更小，不支持则降级为 JPG/PNG）。

### 示例 1：根据视口宽度加载不同比例的图片

```html
<picture>
    <!-- 视口≤768px（手机）：加载竖版图片 -->
    <source media="(max-width: 768px)" srcset="images/mobile-600x800.jpg" />
    <!-- 视口≤1200px（平板）：加载横版中等尺寸 -->
    <source media="(max-width: 1200px)" srcset="images/tablet-1000x500.jpg" />
    <!-- 其他情况（桌面）：加载大尺寸横版 -->
    <source srcset="images/desktop-1600x800.jpg" />
    <!-- 降级方案：所有条件都不匹配/不支持picture时加载此图 -->
    <img
        src="images/fallback.jpg"
        alt="不同设备适配不同图片"
        style="width: 100%; height: auto;"
        <!--
        保证响应式缩放
        --
    />
    >
</picture>
```

### 示例 2：优先加载 WebP 格式（体积更小）

```html
<picture>
    <!-- 浏览器支持WebP：加载webp格式（体积比jpg小30%-50%） -->
    <source
        type="image/webp"
        srcset="images/400w.webp 400w, images/800w.webp 800w"
        sizes="(max-width: 600px) 100vw, 800px"
    />
    <!-- 不支持WebP：加载jpg格式 -->
    <source srcset="images/400w.jpg 400w, images/800w.jpg 800w" sizes="(max-width: 600px) 100vw, 800px" />
    <!-- 最终降级 -->
    <img src="images/400w.jpg" alt="WebP格式优先加载" style="width: 100%; height: auto;" />
</picture>
```

**关键解释**：

-   `<source>` 按书写顺序匹配，浏览器会加载第一个满足条件的`<source>`；
-   `media` 属性：接受 CSS 媒体查询（如`(max-width: 768px)`）；
-   `type` 属性：指定图片 MIME 类型（如`image/webp`、`image/jpeg`），用于格式检测；
-   **必须保留`<img>`标签**：`<picture>`本身不显示图片，仅作为容器，`<img>`是最终的显示和降级载体。

---

### 总结

1. **srcset + sizes**：适合为「同一张图片」提供不同尺寸版本，让浏览器根据视口/像素密度自动选择，核心优化“同图适配”；
2. **<picture>标签**：适合提供「不同格式/不同内容」的图片（如 WebP 优先、横竖版适配），支持更灵活的媒体条件匹配；
3. 核心原则：无论哪种方式，都要保留`<img>`标签和`src`属性作为降级方案，确保全浏览器兼容。
