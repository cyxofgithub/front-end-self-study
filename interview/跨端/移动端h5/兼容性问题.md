## 一、兼容性问题（H5 最核心的痛点）

### 1. 不同浏览器 / 设备样式不一致（如 input、button、select 默认样式）

-   现象：同一段 CSS 在微信浏览器、安卓原生浏览器、iOS Safari 中显示效果差异大（比如 button 圆角、input 内边距）。
-   原因：不同浏览器对 HTML 元素的默认样式（User Agent StyleSheet）定义不同；移动端系统（iOS / 安卓）的渲染引擎差异。
-   解决方案：
    -   初始化样式：使用 reset.css 或 **normalize.css**（推荐后者，保留合理默认样式 + 统一差异）；
    -   针对表单元素：手动重置默认样式（如 appearance: none;清除原生外观，自定义样式）；
    -   关键样式加浏览器前缀：如-webkit-border-radius、-moz-box-shadow（可通过 Autoprefixer 自动补全）。

### CSS3/ES6 + 特性在低版本浏览器不兼容

### 移动端横竖屏切换样式错乱

-   现象：横竖屏切换后，布局宽度、字体大小、图片比例异常。
-   原因：视口（viewport）未适配横竖屏，或 CSS 未针对横竖屏做响应式处理。
-   解决方案：
    -   固定视口：<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">；
    -   媒体查询适配横竖屏：

```css
/* 竖屏 */
@media screen and (orientation: portrait) {
    ...;
}
/* 横屏 */
@media screen and (orientation: landscape) {
    ...;
}
```

    -   监听横竖屏事件：动态调整样式或布局：

```js
window.addEventListener('orientationchange', () => {
    // 重新计算布局/刷新页面（慎用刷新，优先动态调整）
    document.body.style.width = window.innerWidth + 'px';
});
```
