## 点击 300 ms 延迟 和 点击穿透

延迟原因：早期移动端浏览器（如 Safari）为了判断用户是单击还是双击缩放页面，会在用户点击后等待 300ms：如果 300ms 内没有第二次点击，才触发 click 事件；如果有，则执行缩放。这是 300ms 延迟的核心成因

事件穿透的原因：移动端事件触发顺序是：touchstart → touchmove → touchend →（300ms 后）click。 -如果上层元素（如弹窗）绑定了 touchend 事件（无 300ms 延迟），点击后上层元素被隐藏 / 移除，此时 300ms 后触发的 click 事件会 “穿透” 到下层的可点击元素（如按钮、链接）上，导致下层元素被意外触发。

解决方案：

-   消除 300ms 延迟：<meta name="viewport" content="user-scalable=no">；
-   用触摸事件替代 click：touchstart/touchend（注意防止误触）；

## 软键盘弹出导致页面布局错乱

-   现象：输入框聚焦后，软键盘弹出，页面被顶起，底部 fixed 元素上移。
-   原因：软键盘弹出后，浏览器视口高度（window.innerHeight）减小，布局重排。
-   解决方案：
    监听 resize/focusin/focusout 事件，动态调整布局：

```javascript
const input = document.querySelector('input');
input.addEventListener('focusin', () => {
    // 软键盘弹出，隐藏底部fixed元素或调整位置
    document.querySelector('.footer').style.display = 'none';
});
input.addEventListener('focusout', () => {
    // 软键盘收起，恢复布局
    document.querySelector('.footer').style.display = 'block';
});
```

## 滚动卡顿

-   现象：页面滚动时不流畅；弹窗遮罩层显示时，底层页面仍能滚动（滚动穿透）。
-   原因：
    -   滚动卡顿：元素嵌套过多、CSS 动画与滚动冲突、未开启硬件加速；
    -   滚动穿透：遮罩层未阻止默认滚动事件。
-   解决方案：
    -   滚动卡顿：
        -   开启硬件加速：transform: translateZ(0)可以强制浏览器开启 3D 渲染模式，为该元素创建一个独立的 GPU 图层；
        -   减少滚动时的重排重绘（如避免 scroll 事件中操作 DOM）；
    -   滚动穿透：

```javascript
// 遮罩层显示时阻止默认滚动
document.querySelector('.mask').addEventListener('touchmove', (e) => {
    e.preventDefault();
});
```
