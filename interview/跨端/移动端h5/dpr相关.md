## 什么是dpr

设备像素比（Device Pixel Ratio）

### 三个场景对比

#### 通俗理解：固定设备，只改变 viewport width 的效果

**统一设备**：dpr=2，物理宽度 750 物理像素，标准 CSS 宽度 375px

**关键理解**：viewport width 决定了 CSS 视口大小，影响页面内容的显示比例

**场景一（width=device-width，即 375px）**：
- CSS 视口：375px
- 假设页面内容宽度：375px
- 内容占满 CSS 视口（100%）
- 375px CSS → 750 物理像素（放大2倍）
- **视觉效果**：正常大小，1 CSS px = 2 物理像素

**场景二（width=750）**：
- CSS 视口：750px（比场景一大了2倍）
- 假设页面内容宽度：375px（固定）
- 内容只占 CSS 视口的 50%（375/750）
- 浏览器会**自动缩放**，让内容占满视口，所以内容被放大2倍
- 750px CSS → 750 物理像素（1:1）
- **视觉效果**：内容被放大，变粗糙，1 CSS px = 1 物理像素

**场景三（width=1125）**：
- CSS 视口：1125px（比场景一大了3倍）
- 假设页面内容宽度：375px（固定，按标准设计）
- **关键**：内容不会被自动拉伸，仍然是 375px
- 375px 的内容在 1125px 的 CSS 视口中，只占 33.3%
- 1125px CSS 视口 → 压缩到 750 物理像素显示（压缩比例 750/1125 = 0.67）
- **视觉效果**：内容看起来更小更密集，1 CSS px = 0.67 物理像素

**总结对比**（假设内容固定为 375px）：
- **场景一**：375px CSS 视口 → 内容占满 → 放大2倍显示 → 正常大小
- **场景二**：750px CSS 视口 → 内容被拉伸占满 → 1:1 显示 → **放大**（因为视口变大）
- **场景三**：1125px CSS 视口 → 内容不变，但视口变大 → 压缩显示 → **缩小**（因为视口太大，内容相对变小）

**关键理解**：
- 场景二：CSS 视口 = 物理宽度，内容被拉伸放大
- 场景三：CSS 视口 > 物理宽度，内容在更大的视口中显得更小，然后压缩显示

#### 总结

- **页面实际渲染物理像素 = CSS 像素 x dpr x (1/initial-scale)**  
- 调整 `initial-scale` 实质上就是调整页面的缩放和内容分布，以及 CSS 像素到设备物理像素的映射关系。
- dpr 和 viewport 搭配使用，能精准地适配不同设备实现高清与多样布局效果。

## 什么时候需要关注 dpr

### 实现 "设计稿级别的 1px 细边框"

| 项目 | 说明 |
|------|------|
| **问题** | 设计稿要求 1px 的细分割线，直接写 `border: 1px solid #eee` |
| **实际效果** | 在 iPhone 13（dpr=3）上会显示成 3 物理像素，线条偏粗 |
| **不符合要求** | 不符合设计要求，需要特殊处理 |

### 图片场景

| 项目 | 说明 |
|------|------|
| **原始图片尺寸** | 200 x 300 物理像素 |
| **设备 DPR** | 2 |
| **CSS 设置** | 图片设置为 200px x 300px |
| **实际占用物理像素** | 200 x 300 x 2 = 120,000 个物理像素 |
| **问题** | 图片会变糊，因为需要更多物理像素来填充 |
| **解决方案** | 需要一张 2x 图（400 x 600 物理像素） |


### canvas 图表绘制

| 项目 | 说明 |
|------|------|
| **CSS 尺寸设置** | Canvas 的 CSS 尺寸为 300px × 150px |
| **Canvas 实际分辨率** | width/height 属性为 300×150 |
| **设备 DPR** | 3（如 iPhone X） |
| **实际渲染物理像素** | 浏览器会拉伸到 900×450 物理像素 |
| **问题** | 绘制的折线图会模糊 |
| **解决方式** | 根据 DPR 放大 Canvas 分辨率，再缩回到 CSS 尺寸 |

```javascript
const canvas = document.getElementById('myChart');
const ctx = canvas.getContext('2d');
const dpr = window.devicePixelRatio || 1;

// 放大分辨率到DPR倍
canvas.width = 300 * dpr;
canvas.height = 150 * dpr;
// 缩回到CSS尺寸
canvas.style.width = '300px';
canvas.style.height = '150px';
// 调整坐标系，避免绘制内容放大
ctx.scale(dpr, dpr);
```
