### WebGL vs WebGPU 核心对比表

| 对比维度     | WebGL                                      | WebGPU                                   |
| ------------ | ------------------------------------------ | ---------------------------------------- |
| 推出时间     | 2011 年（WebGL 1.0）、2017 年（WebGL 2.0） | 2023 年（稳定版）                        |
| 维护组织     | Khronos Group                              | W3C GPU For the Web 工作组               |
| 底层基于     | OpenGL ES（嵌入式图形 API）                | Direct3D 12/Vulkan/Metal（现代 GPU API） |
| 编程模型     | 全局状态机                                 | 命令式+面向资源                          |
| 核心能力     | **仅支持图形渲染（有限 GPGPU 技巧实现）**  | **支持高性能图形渲染+通用 GPU 计算**     |
| 浏览器兼容性 | 极强（全现代浏览器+部分老旧浏览器）        | 较好（仅最新版现代浏览器）               |
| 生态成熟度   | 极高（大量库、教程、案例）                 | 中等（快速发展中，主流图形库已支持）     |
| 学习曲线     | 较平缓（新手易入门）                       | 较陡峭（需理解更多 GPU 底层概念）        |

### 总结

1.  **WebGL**是老牌 Web 图形 API，胜在兼容性极强、生态成熟，适合轻量 3D 场景和对兼容性要求高的开发，是新手入门 **Web 图形渲染**的优选。
2.  **WebGPU**是新一代 Web 图形/计算 API，性能强劲、功能全面（支持 GPGPU），贴合现代 GPU 架构，是未来 Web 端**复杂图形渲染和高性能计算**的主流方向。
3.  实际开发中，可根据浏览器兼容性要求和场景复杂度选择：简单场景用 WebGL 快速落地，复杂高性能场景用 WebGPU（同时可做 WebGL 降级兼容）。
