## 🛠️ Figma MCP 工具作用梳理表
| 接口名                        | 作用说明 |
|-------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| get_design_context            | 获取当前 Figma 文件的设计上下文信息，包含页面结构、组件层级、样式环境等基础数据，为后续操作提供设计环境的上下文支撑。 |
| get_variable_defs             | 拉取 Figma 文件中所有变量（Variables）的定义信息，包括变量类型（颜色 / 字体 / 数值等）、变量值集合、作用域等，便于开发流程复用设计变量。 |
| get_screenshot                | 生成当前选中设计元素（或整个画布）的截图，用于开发时视觉参考、文档嵌入，确保开发与设计视觉对齐。 |
| get_code_connect_map          | 获取已配置的设计 - 代码映射关系（Code Connect 是 Figma 关联设计与代码的能力），查看哪些设计元素已绑定到对应的代码组件 / 属性。 |
| add_code_connect_map          | 新增设计 - 代码映射规则，将设计组件与代码实现（如前端组件、样式类）绑定，让开发时可直接从设计跳转至对应代码。 |
| get_strategy_for_mapping      | 获取设计元素映射到代码的策略逻辑，例如不同类型的设计元素（组件 / 样式 / 变量）该用何种规则映射到代码，保障映射的一致性。 |
| send_get_strategy_response    | 向调用方返回映射策略的结果数据，与 get_strategy_for_mapping 配合，为后续映射操作提供策略依据。 |
| get_metadata                  | 获取设计文件 / 元素的元信息，如文件版本、作者、元素 ID、创建时间等，用于设计资源的追溯与管理。 |
| create_design_system_rules    | 定义新的设计系统规则，包括组件约束、样式复用规范、变量联动逻辑等，保障设计系统的一致性与可维护性。 |
| get_figjam                    | 拉取 FigJam（Figma 协作白板工具）中的内容与数据，支持在 Dev Mode 中处理 FigJam 协作产生的信息。 |
| get_code_for_selection        | 根据当前选中的设计元素，自动生成对应的代码片段（如 React 组件、CSS 样式），直接供开发使用，减少手写代码成本。 |
| map_selection_to_code_connect | 将当前选中的设计元素与已有的 Code Connect 映射关联，确保选中元素能精准对应到目标代码实现，提升开发效率。 |
