我用**最简单、最容易记**的方式，给你讲清楚：
**为什么锥型 NAT 能穿透，对称型不行。**

---

# 先记住一句话

**锥型 NAT：端口不变，谁都能进。
对称型 NAT：端口会变，只认熟人。**

---

# 1. 先看 3 种“能穿透”的 NAT

它们都属于 **锥型 NAT（Cone NAT）**

## ① 完全锥型（Full Cone）

-   内网端口 → 永远映射到 **同一个公网端口**
-   **任何人**往这个公网端口发包，都能进你内网
-   最宽松，最容易穿透

## ② 限制锥型（Restricted Cone）

-   端口还是 **不变**
-   但只允许 **你主动发过包的 IP** 回包
-   端口不变 → 能穿透

## ③ 端口限制锥型（Port-Restricted Cone）

-   端口依然 **不变**
-   只允许 **你主动发过包的 IP:端口** 回包
-   端口不变 → 依然能穿透

---

# 2. 锥型为什么能穿透？（核心）

因为：
**你内网一个端口 → 永远对应一个公网端口**

穿透流程：

1. 你去 STUN 测一下 → 拿到你的公网 IP:端口
2. 把这个地址发给对方
3. 对方往这个地址发包
4. NAT 一看：端口对得上 → 放行

**端口不变 = 能预测 = 能打洞**

---

# 3. 对称型为什么不行？

**每访问一个不同的目标 IP:端口，就换一个新公网端口！**

-   你访问 STUN → 端口 A
-   你访问朋友 → 端口 B
-   你访问另一个人 → 端口 C

STUN 拿到的端口 A，**只对 STUN 有效**
朋友用端口 A 发你 → NAT 直接丢包

**端口一直在变 = 无法预测 = 无法打洞**

---

# 4. 超简总结（面试直接背）

-   **锥型 NAT（3 种）：端口不变 → 能穿透**
-   **对称型 NAT：端口随目标变化 → 无法穿透**

能穿透的关键只有一个：
**端口复用、端口不变！**
