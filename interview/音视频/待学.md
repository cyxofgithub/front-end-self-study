## 基础二进制处理

-   Blob/File/ArrayBuffer 二进制处理

## 前端原生音视频核心 API

-   HTMLMediaElement（audio/video 标签）
    -   常用属性：src/currentTime/duration/volume/paused
    -   常用方法：play()/pause()/load()
    -   关键事件：canplay/timeupdate/ended/error/waiting/stalled
    -   Web Audio API: 音量、降噪、均衡器、音频可视化、混音
    -   WebCodecs（现代必学）: 浏览器原生音视频编解码，性能远超 WASM 方案

## 流媒体播放（直播 / 点播核心）

-   MSE – Media Source Extensions

    -   让浏览器能播放「分段流」，是所有直播播放器的底层

-   主流协议与库
    -   HLS → hls.js
    -   DASH → dash.js
    -   FLV → flv.js
    -   通用播放器 → video.js、xgplayer

## 前端音视频处理

-   ffmpeg.wasm
    -   前端实现：裁剪、合并、转码、格式转换、提取音频
-   视频帧处理
    -   截取帧、逐帧分析、AI 识别、美颜滤镜
-   音频处理
    -   降噪、回声消除、音量增益

## 最推荐学习路径（最快落地）

-   先吃透：<video> + 事件 + 自定义播放器
-   再学：MSE + hls.js/flv.js 做直播
-   进阶：WebRTC 做通话
-   拔高：WebCodecs + ffmpeg.wasm 做剪辑 / 转码
