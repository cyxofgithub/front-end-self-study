## 总结

### 设计思路总结

通过以上 5 个实战案例，我们学到了：

1. **商品缓存**：多级缓存策略，解决缓存穿透、击穿、雪崩问题
2. **点赞计数**：使用 Redis 原子操作保证计数准确性，结合排行榜提升性能
3. **秒杀限流**：令牌桶算法限流 + Lua 脚本保证原子性，防止超卖
4. **Session 存储**：使用 Redis 存储 Session，解决分布式系统会话共享问题
5. **延迟队列**：使用有序集合实现延迟队列，支持消息去重和优先级

### 核心原则

-   ✅ **缓存策略**：合理使用缓存，注意缓存穿透、击穿、雪崩的防护
-   ✅ **原子操作**：使用 Redis 原子操作或 Lua 脚本保证数据一致性
-   ✅ **性能优化**：合理使用数据结构，避免大 key 和热 key 问题
-   ✅ **过期策略**：合理设置过期时间，平衡内存使用和数据新鲜度
-   ✅ **降级方案**：设计缓存降级策略，保证系统可用性

**记住**：Redis 设计没有标准答案，只有最适合当前业务场景的方案。多实践、多思考、多总结！
